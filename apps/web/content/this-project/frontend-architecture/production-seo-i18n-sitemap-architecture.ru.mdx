## 1. Трёхуровневая матрица локалей (`Internal Code` vs `URL Prefix` vs `Hreflang / OpenGraph`)

Главная особенность мультиязычного SEO в нашем проекте — то, что код языка внутри системы, публичный префикс в адресной строке браузера и стандартные коды для поисковых роботов Google / мессенджеров (Telegram, LinkedIn, Slack) подчиняются разным спецификациям.

В `apps/web/src/shared/i18n/routing.ts` включён режим `localePrefix: { mode: 'as-needed', prefixes: { uk: '/ua' } }`. Чтобы ни на одной странице не возникало расхождений, модуль `apps/web/src/shared/lib/seo.ts` разделяет эти представления:

| Язык | Внутренний тип (`SupportedLocale` и суффикс `.mdx`) | Публичный URL-префикс (`as-needed`) | Поисковый стандарт ISO 639-1 (`<html lang>` и `hreflang`) | Стандарт мессенджеров (`og:locale`) |
| :--- | :--- | :--- | :--- | :--- |
| **English (Default)** | `'en'` (`*.en.mdx`) | Без префикса (`/`, `/cv`, `/knowledge-base`) | `en` (+ `x-default`) | `en_US` |
| **Українська** | `'uk'` (`*.uk.mdx`) | `/ua` (`/ua`, `/ua/cv`, `/ua/knowledge-base`) | `uk` | `uk_UA` |
| **Русский** | `'ru'` (`*.ru.mdx`) | `/ru` (`/ru`, `/ru/cv`, `/ru/knowledge-base`) | `ru` | `ru_RU` |

> [!IMPORTANT]
> По спецификации Google Search Central атрибут `hreflang` обязан использовать код языка по стандарту **ISO 639-1** (`uk` для украинского языка, а не код страны `ua`), но сам `href` внутри этого тега должен указывать на реальный публичный маршрут сайта (`https://domain.com/ua/...`). Именно поэтому в `buildLanguageAlternatesMap()` ключ словаря — `uk`, а сгенерированный URL ведёт на префикс `/ua`.

## 2. Единое SEO-ядро и защита от невалидного Origin (`apps/web/src/shared/lib/seo.ts`)

Все SEO-вычисления вынесены в чистые серверные функции без внешних зависимостей:

```typescript title="apps/web/src/shared/lib/seo.ts"
const DEFAULT_SITE_URL = 'http://localhost:3000'

const LOCALE_URL_PREFIX_MAP: Record<SupportedLocale, string> = {
  en: '',
  uk: '/ua',
  ru: '/ru',
}

const OG_LOCALE_MAP: Record<SupportedLocale, string> = {
  en: 'en_US',
  uk: 'uk_UA',
  ru: 'ru_RU',
}

export function resolveSiteUrl(): string {
  const raw = process.env.NEXT_PUBLIC_SITE_URL?.trim()
  if (!raw) return DEFAULT_SITE_URL

  try {
    const parsed = new URL(raw)
    if (parsed.protocol !== 'http:' && parsed.protocol !== 'https:') {
      return DEFAULT_SITE_URL
    }
    return parsed.origin
  } catch {
    return DEFAULT_SITE_URL
  }
}
```

### Почему `resolveSiteUrl()` возвращает `parsed.origin` через `new URL(raw)`?
В `apps/web/src/app/[locale]/layout.tsx` вызывается `metadataBase: new URL(resolveSiteUrl())`. Если в переменной окружения `NEXT_PUBLIC_SITE_URL` на хостинге случайно окажется строка без протокола, с лишним слэшем или путём (например, `example.com/`), прямое создание `new URL()` без `try/catch` уронит сборку `next build`, а некорректный протокол может нарушить целостность `<link rel="canonical">`. Валидация через `parsed.origin` гарантирует чистый `https://domain.com` или безопасный откат на `http://localhost:3000`.

## 3. Генерация `canonical`, `alternates.languages` (`hreflang`) и `openGraph`

Функция `buildPageAlternates(pathname, locale)` вызывается внутри `generateMetadata()` на всех уровнях маршрутизации (`[locale]/layout.tsx`, `[locale]/cv/page.tsx`, `[locale]/knowledge-base/page.tsx` и `[locale]/knowledge-base/[...slug]/page.tsx`):

```typescript title="apps/web/src/shared/lib/seo.ts"
export function buildLanguageAlternatesMap(pathname: string): Record<string, string> {
  return {
    en: buildLocalizedUrl(pathname, 'en'),
    uk: buildLocalizedUrl(pathname, 'uk'),
    ru: buildLocalizedUrl(pathname, 'ru'),
    'x-default': buildLocalizedUrl(pathname, DEFAULT_LOCALE),
  }
}

export function buildPageAlternates(pathname: string, locale: SupportedLocale = DEFAULT_LOCALE) {
  return {
    canonical: buildLocalizedUrl(pathname, locale),
    languages: buildLanguageAlternatesMap(pathname),
  }
}
```

На основе этого объекта Next.js 16 автоматически рендерит в `<head>`:
- **`<link rel="canonical">`** — авторитетный URL текущей локали (защищает от дублей в индексе при наличии query-параметров вроде `?unlock=knowledge-base`).
- **Связку `<link rel="alternate" hreflang="en | uk | ru | x-default">`** — перекрёстные ссылки на все языковые версии страницы согласно матрице из Раздела 1 (`x-default` указывает на дефолтную английскую версию без префикса).
- **Мета-теги `openGraph` (`og:title`, `og:description`, `og:url`, `og:locale`, `og:type`, `og:image`)** — локализованные карточки Rich Link Preview для **Telegram, LinkedIn, Slack и Discord** (для статей Базы Знаний также добавляются `og:type="article"`, `article:published_time` и `article:tag`).

## 4. File-Based Metadata (`robots.ts`, `sitemap.ts`, `opengraph-image.tsx`, `icon.tsx`) и Edge Proxy

Все мета-маршруты в `apps/web/src/app/` компилируются на этапе сборки (`SSG`, `0 КБ` клиентского JS) и обходят проверки JWT в `apps/web/src/proxy.ts` благодаря регулярному выражению `matcher`:

```typescript title="apps/web/src/proxy.ts"
export const config = {
  matcher: ['/((?!api|search-index|icon|apple-icon|_next|_vercel|.*opengraph-image.*|.*\\..*).*)'],
}
```

1. **Изоляция служебных эндпоинтов в `robots.ts`:** правило `disallow: ['/api/', '/search-index/']` закрывает от поисковых краулеров REST/SSE-потоки бэкенда (`/api/telemetry/stream`) и сырые JSON-индексы модалки `Cmd+K`.
2. **Автоматический обход дерева `.mdx` в `sitemap.ts`:** объединяет корневые хабы (`/`, `/cv`, `/knowledge-base`) со всеми путями из `getAllStaticKnowledgeSlugArrays()` и реальными датами `publishedAt` из `getAllKnowledgeFrontmatters(DEFAULT_LOCALE)`.
3. **Кодогенерация графики через `next/og` (`ImageResponse` / Satori):**
   - `apps/web/src/app/icon.tsx` (`32×32`) и `apple-icon.tsx` (`180×180`) генерируют обсидиановую иконку терминала `>_`.
   - `apps/web/src/app/[locale]/opengraph-image.tsx` (`1200×630`) рендерит фирменный баннер `Obsidian Editorial Dark` для каждой локали (`generateStaticParams`) без внешних сетевых запросов за шрифтами, а в `layout.tsx` включена директива `googleBot: { 'max-image-preview': 'large' }` и адаптивный `viewport.themeColor` (`#FAF8F5` / `#121211`) для мобильных шторок Safari и Chrome.
   - **Предотвращение Soft-404 в индексе:** для любых несуществующих URL внутри локали catch-all маршрут `app/[locale]/[...rest]/page.tsx` синхронно вызывает `notFound()`, отдавая поисковому роботу строгий HTTP-статус `404` внутри локализованного серверного компонента `app/[locale]/not-found.tsx`.
4. **Структурированные данные `JSON-LD` (`Schema.org`) и AI-манифест `/llms.txt`:**
   - Хелперы `buildProfilePageJsonLd()` и `buildTechArticleJsonLd()` в `seo.ts` генерируют серверный `<script type="application/ld+json">` (с экранированием `<` ➔ `\u003c` против XSS) на главной странице (`/`), резюме (`/cv`) и во всех конспектах Базы Знаний (`/knowledge-base/[...slug]`).
   - Статический маршрут `apps/web/src/app/llms.txt/route.ts` (`force-static`) формирует машиночитаемый Markdown-паспорт портфолио (профиль, коммерческий трек-рекорд с метриками, 16 ADR и полное оглавление Базы Знаний) специально для LLM-агентов (**ChatGPT Search, Claude, Perplexity, Cursor**).

## 5. Архитектурный реестр SEO-подсистемы

| Компонент SEO | Файл / Расположение | Назначение в продакшене |
| :--- | :--- | :--- |
| **SEO Core & JSON-LD Builders** | `apps/web/src/shared/lib/seo.ts` | Валидация `NEXT_PUBLIC_SITE_URL` (`parsed.origin`), генерация `canonical`, `hreflang`, `og:locale` и `JSON-LD` (`ProfilePage` / `TechArticle`) |
| **Adaptive Viewport & GoogleBot Rules** | `apps/web/src/app/[locale]/layout.tsx` | Системный `theme-color` (`#FAF8F5` / `#121211`), `authors`/`creator` и `max-image-preview: 'large'` |
| **Turborepo Env Invalidation** | `turbo.json` (`globalEnv`) | Автоматическая пересборка SSG-метаданных при смене `NEXT_PUBLIC_SITE_URL` |
| **Robots.txt Generator** | `apps/web/src/app/robots.ts` | Статические правила индексации (`allow: '/'`, `disallow: ['/api/', '/search-index/']`) |
| **Multilingual Sitemap.xml** | `apps/web/src/app/sitemap.ts` | Полная карта локализованных маршрутов (`EN / UA / RU`) с `lastModified` из `.mdx` |
| **AI Discovery Manifest (`/llms.txt`)** | `apps/web/src/app/llms.txt/route.ts` | Структурированный Markdown-манифест опыта, 16 ADR и каталога статей для AI-поисковиков |
| **OpenGraph Social Banner (`1200×630`)** | `apps/web/src/app/[locale]/opengraph-image.tsx` | Статическая кодогенерация карточек `Obsidian Editorial Dark` через `next/og` |
| **Browser & Apple Icons (`32×32`, `180×180`)** | `apps/web/src/app/icon.tsx`, `apple-icon.tsx` | Векторная генерация фавиконок `>_` через `ImageResponse` |
| **Strict HTTP 404 Catch-All** | `apps/web/src/app/[locale]/[...rest]/page.tsx` + `not-found.tsx` | Защита от Soft-404: возврат честного HTTP `404` с сохранением навигации `LocaleRootLayout` |
