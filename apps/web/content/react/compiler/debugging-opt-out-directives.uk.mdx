## 1. Перевірка бейджа `Memo ✨` у React DevTools

Відкрийте вкладку **Components** у **React DevTools**: поруч із кожним скомпільованим компонентом з’являється значок **`Memo ✨`**. Якщо бейджа немає — компілятор знайшов порушення чистоти рендеру й безпечно залишив компонент у стандартному режимі.

## 2. Керуючі директиви `'use no memo'` та `'use memo'`

```tsx title="Точкове вимкнення для мутабельної сторонньої бібліотеки"
export function LegacyChartWrapper({ mutableInstance }: { mutableInstance: ExternalChart }) {
  'use no memo'
  // Компілятор пропускає цю функцію, щоб зовнішні мутації не кешувалися
  return <div data-chart-version={mutableInstance.version} />
}
```

| Режим / Директива | Дія | Коли застосовувати |
| :--- | :--- | :--- |
| За замовчуванням (`all`) | Оптимізує всі валідні компоненти й хуки | Сучасні проєкти на Next.js 16 (наш стек) |
| `'use no memo'` | Вимикає оптимізацію однієї функції | Ізоляція багів зі сторонніми мутабельними SDK |
| `'use memo'` (`annotation`) | Ручне ввімкнення для обраних файлів | Плавна міграція великих старих монолітів |
