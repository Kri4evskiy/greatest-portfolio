## 1. Архітектура маршруту `/[locale]/knowledge-base/[...slug]` і потоковий `Suspense`

Конспекти зберігаються на диску за шаблоном `apps/web/content/<topic>/<subtopic>/<slug>.<locale>.mdx`. Публічні URL підпорядковуються режиму `as-needed` у `next-intl` (англійська `en` за замовчуванням **без префікса**, українська `uk` використовує **`/ua`**, російська `ru` — **`/ru`**). Один catch-all маршрут `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx` обслуговує будь-яку глибину вкладеності:

| Глибина `slug` | Приклад публічного URL (UA) | Що рендерить `page.tsx` |
| :--- | :--- | :--- |
| **1 сегмент (`[topic]`)** | `/ua/knowledge-base/this-project` | **Хаб теми:** вкладки підтем (`TopicSubtopicTabs`), картки підрозділів та список усіх статей розділу |
| **2 сегменти (`[topic, subtopic]`)** | `/ua/knowledge-base/this-project/knowledge-engine` | **Хаб підтеми:** активна вкладка підтеми та відфільтровані картки конспектів цієї папки |
| **3 сегменти (`[...path, article]`)** | `/ua/knowledge-base/this-project/knowledge-engine/server-mdx-ast-dual-theme-shiki` | **Сторінка статті:** `TL;DR`, `<Suspense fallback={<ArticleBodySkeleton />}>`, `MdxArticleRenderer`, правий `TOC` і `Prev / Next` |

На етапі збірки `export const dynamicParams = false` жорстко обмежує маршрутизацію шляхами з `generateStaticParams()` (миттєво віддаючи `404` для невідомих слагів), а `<MdxArticleRenderer>` обгорнутий у `<Suspense fallback={<ArticleBodySkeleton />}>` (із `apps/web/src/entities/knowledge-article/ui/knowledge-skeletons.tsx`):

```tsx title="apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx"
export const dynamicParams = false

export function generateStaticParams() {
  const slugArrays = getAllStaticKnowledgeSlugArrays()
  return SUPPORTED_LOCALES.flatMap((locale) =>
    slugArrays.map((slug) => ({
      locale,
      slug,
    })),
  )
}

// У гілці рендера статті всередині KnowledgeCatchAllPage:
<Suspense fallback={<ArticleBodySkeleton />}>
  <MdxArticleRenderer hast={article.hast} codeBlocks={article.codeBlocks} />
</Suspense>
```

### Дедуплікація через примітивно-ключований `React.cache` (`mdx-fs-loader.ts`)
Next.js передає в `generateMetadata()` та `Page()` різні екземпляри масиву `slug: string[]`, через що пряме кешування за масивом у `React.cache` дає промах за посиланням. В `apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts` сегменти спершу склеюються в примітивний рядковий ключ (`segments.join('/')`), завдяки чому обидва виклики ділять один і той самий мемоїзований документ поверх міжзапитного `mtimeMs`-кешу:

```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts"
const getArticleByRouteKey = cache((targetRoute: string, locale: SupportedLocale): MdxArticleDocument | null => {
  const entries = getAllCachedFrontmatterEntriesByLocale(locale)
  const matchedEntry = entries.find((e) => e.frontmatter.routePath === targetRoute)
  if (!matchedEntry) return null
  return loadCachedDocumentFromEntry(matchedEntry)
})

export function getArticleByPathSegments(segments: readonly string[], localeInput?: string): MdxArticleDocument | null {
  return getArticleByRouteKey(segments.join('/'), normalizeLocale(localeInput))
}
```

## 2. Загартований Zero-Eval HAST-конвеєр і санітайзер посилань

Парсинг `.mdx`-файлів виконується виключно на сервері в `apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts`:

1. **RCE-захист `gray-matter` (`parseFrontmatterOnly`):** явно вимикає legacy-рушії `js` та `javascript` для виконання коду в YAML-фронтматері (defense-in-depth):
   ```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts"
   const parsedMatter = matter(raw, {
     engines: {
       js: () => ({}),
       javascript: () => ({}),
     },
   })
   ```
2. **Zero-Eval `mdast` ➔ `HAST` (`unified`):** `remarkParse` + `remarkGfm` + `remarkDirective` розмічає заголовки `h2–h4`, GitHub Alerts (`> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`), чеклісти й блоки коду, конвертує зареєстровані теги `<Widget />` і директиви `::sandbox` / `:::sandbox` у `div[data-mdx-widget]` та вирізає довільний сирий HTML перед передачею в `remarkRehype` і `toJsxRuntime`.
3. **Захист від protocol-relative та `/\` обходів (`apps/web/src/entities/knowledge-content/lib/link-sanitizer.ts`):** `classifySafeMarkdownLink()` і `isSafeMarkdownImageSrc()` блокують як `//`, так і шляхи зі зворотним слешем `/\` (`!trimmed.startsWith('//') && !trimmed.startsWith('/\\')`), дозволяючи лише `http:`, `https:`, `mailto:` (для посилань) та `http:`, `https:` (для зображень).

## 3. Dual-Theme `Shiki v4` із FIFO-кешем і стилями в `theme.css` (`0 КБ` клієнтського JS)

`MdxArticleRenderer` підсвічує всі `codeBlocks` паралельно через `Promise.all` і `highlightCodeServer` (`apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts`):

```typescript title="apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts"
const SHIKI_THEMES = {
  light: 'github-light-default',
  dark: 'github-dark-default',
} as const

const MAX_SHIKI_CACHE_ENTRIES = 1000

async function renderHighlightedHtml(code: string, lang: string): Promise<string> {
  try {
    return await codeToHtml(code, { lang, themes: SHIKI_THEMES, defaultColor: false })
  } catch {
    try {
      return await codeToHtml(code, { lang: 'text', themes: SHIKI_THEMES, defaultColor: false })
    } catch {
      return `<pre class="shiki"><code>${escapeHtmlFallback(code)}</code></pre>`
    }
  }
}

export function highlightCodeServer(code: string, rawLanguage: string): Promise<string> {
  const normalized = rawLanguage.trim().toLowerCase()
  const lang = LANGUAGE_ALIASES[normalized] ?? (normalized || 'typescript')
  const cacheKey = `${lang}\0${code}`

  const existing = shikiCache.get(cacheKey)
  if (existing) return existing

  const promise = renderHighlightedHtml(code, lang).catch((error: unknown) => {
    shikiCache.delete(cacheKey)
    throw error
  })

  // FIFO-витіснення запобігає різкій просадці (cold-start cliff) при повному скиданні кешу
  if (shikiCache.size >= MAX_SHIKI_CACHE_ENTRIES) {
    const oldestKey = shikiCache.keys().next().value
    if (oldestKey !== undefined) {
      shikiCache.delete(oldestKey)
    }
  }
  shikiCache.set(cacheKey, promise)
  return promise
}
```

- **FIFO-витіснення (`MAX_SHIKI_CACHE_ENTRIES = 1000`):** при заповненні видаляє лише найстаріший ключ замість очищення всієї `Map`, виключаючи стрибки латентності.
- **Самоочищення через `.catch()`:** миттєво видаляє відхилений проміс із кешу, щоб поодинокий збій не отруїв ключ сніпета назавжди.
- **Zero-JS CSS-каскад (`packages/ui/src/styles/theme.css`):** із `defaultColor: false` Shiki записує змінні `--shiki-light` та `--shiki-dark`, які перемикаються чистим CSS у `@layer components`:

```css title="packages/ui/src/styles/theme.css"
@layer components {
  .shiki,
  .shiki span {
    color: var(--shiki-light);
    background-color: transparent;
    font-style: var(--shiki-light-font-style, inherit);
    font-weight: var(--shiki-light-font-weight, inherit);
  }

  .dark .shiki,
  .dark .shiki span {
    color: var(--shiki-dark);
    background-color: transparent;
    font-style: var(--shiki-dark-font-style, inherit);
    font-weight: var(--shiki-dark-font-weight, inherit);
  }
}
```

## 4. Ліниві MDX-віджети (`next/dynamic`) і tree-shaken імпорти `d3`

Усі 4 інтерактивні віджети в `apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx` (`ReactRenderGraphD3`, `ArchitectureFlowD3`, `NestAiMcpDiagram`, `ArticleImageGrid`) завантажуються динамічно з `ssr: false` та скелетонами фіксованої висоти (`min-h-[420px]` / `min-h-[320px]`), тому текстові статті без віджетів отримують рівно **0 КБ** коду діаграм і D3:

```tsx title="apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx"
const ReactRenderGraphD3 = dynamic(() => import('./d3-react-render-graph').then((m) => m.ReactRenderGraphD3), {
  ssr: false,
  loading: () => <Skeleton className="my-6 min-h-[420px] w-full rounded-xl" />,
})
```

Усередині D3-пісочниць (`d3-react-render-graph.tsx`, `d3-architecture-flow.tsx`) замість повного `import * as d3` використовуються **іменовані tree-shaken імпорти** (`import { hierarchy, linkHorizontal, select, tree } from 'd3'` та `import { select } from 'd3'`), підсилені опцією `experimental.optimizePackageImports: ['lucide-react', 'd3', '@repo/ui', '@repo/shared-schemas']` в `apps/web/next.config.ts`.
