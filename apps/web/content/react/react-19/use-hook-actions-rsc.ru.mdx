## 1. API `use()`: потоковые промисы и условный контекст

В отличие от классического `useContext`, функцию `use()` разрешено вызывать после ранних `return` и внутри условных веток `if`.

### Потоковая передача промиса из Server Component на клиент

```tsx title="Стриминг промиса без блокировки SSR"
'use client'
import { use } from 'react'

export function MetricsSummary({ metricsPromise }: { metricsPromise: Promise<MetricsDto> }) {
  const data = use(metricsPromise)
  return <span className="font-mono">{data.viewsCount} просмотров</span>
}
```

> [!TIP]
> Запускайте промис в **Server Component** без `await`, оборачивайте клиентский виджет в `<Suspense>` и раскрывайте данные через `use(promise)` — так HTML страницы улетает в браузер мгновенно без серверного водопада (`waterfall`).

## 2. Главные эргономические улучшения в React 19

| Задача | Бойлерплейт в React 18 | Стандарт в React 19 |
| :--- | :--- | :--- |
| Проброс `ref` в инпут/кнопку | `forwardRef<HTMLInputElement, Props>((props, ref) => ...)` | `function Input({ ref, ...props }: Props)` |
| Объявление провайдера | `<ThemeContext.Provider value={theme}>` | `<ThemeContext value={theme}>` |
| Сабмит и лоадер мутации | Ручные `useState` для `isLoading` и `error` | `const [state, action, isPending] = useActionState(...)` |
| Метаданные документа | Сторонние обёртки или ручная работа с `head` | Нативный подъём `<title>`, `<meta>`, `<link>` в `<head>` |
