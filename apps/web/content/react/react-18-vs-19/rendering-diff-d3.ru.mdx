## 1. Ключевые отличия React 18 и React 19

| Критерий | React 18 (Ручная мемоизация) | React 19 (Compiler + RSC) |
| :--- | :--- | :--- |
| Ререндер поддерева | Каскадный вниз по дереву без `React.memo` | Автоматическое отсечение неизменившихся веток JSX |
| Стабильность ссылок | Ручные массивы зависимостей `useCallback` | Слоты мемоизации, сгенерированные при сборке |
| Чтение промисов | Водопады в `useEffect` или сторонний стор | Потоковый `use(promise)` внутри `<Suspense>` |
| Работа с `ref` | Обязательная обёртка `forwardRef` | Обычный проп `ref` в функциональном компоненте |

## 3. Интеграция `D3.js` без конфликтов с Virtual DOM

Чтобы императивная анимация `D3.js` не конфликтовала с React, координаты узлов никогда не кладутся в React-стейт:

```typescript title="Локальный режим виджета + изолированный useRef"
const [mode, setMode] = useState<ReactRenderMode>('react19')
const svgRef = useRef<SVGSVGElement | null>(null)
```

- **Изоляция DOM:** React владеет только корневым `<svg ref={svgRef} />`, а построение `d3.tree()` и `d3.linkHorizontal()` выполняется императивно внутри `useEffect`.
- **Ленивые чанки (`next/dynamic`):** Модули `D3.js` не попадают в стартовый JS-бандл страницы резюме и грузятся по требованию.
