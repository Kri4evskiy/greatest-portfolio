## 1. The 3-Tier Locale Matrix (`LOCALE_METADATA` Single Source of Truth)

A core nuance of multilingual SEO in this monorepo is that internal locale codes, public browser URL prefixes, BCP 47 tags, and search engine / social messenger specifications follow different standards.

Rather than duplicating lookup maps across frontend modules, `packages/shared-schemas/src/locale.schema.ts` exports `LOCALE_METADATA` as the single source of truth consumed by `apps/web/src/shared/lib/seo.ts`, `robots.ts`, and `apps/web/src/shared/i18n/routing.ts` (`localePrefix: { mode: 'as-needed', prefixes: { uk: '/ua' } }`):

| Language | Internal Type (`SupportedLocale` & `.mdx` suffix) | Public URL Prefix (`urlPrefix`) | Search Engine ISO 639-1 (`<html lang>` & `hreflang`) | Messenger Standard (`ogLocale`) |
| :--- | :--- | :--- | :--- | :--- |
| **English (Default)** | `'en'` (`*.en.mdx`) | `''` (`/`, `/cv`, `/system-status`, `/knowledge-base`) | `en` (+ `x-default`) | `en_US` |
| **Ukrainian** | `'uk'` (`*.uk.mdx`) | `'/ua'` (`/ua`, `/ua/cv`, `/ua/system-status`, `/ua/knowledge-base`) | `uk` | `uk_UA` |
| **Russian** | `'ru'` (`*.ru.mdx`) | `'/ru'` (`/ru`, `/ru/cv`, `/ru/system-status`, `/ru/knowledge-base`) | `ru` | `ru_RU` |

> [!IMPORTANT]
> According to Google Search Central guidelines, the `hreflang` attribute must use the **ISO 639-1** language code (`uk` for Ukrainian, not the country code `ua`), while its `href` attribute must resolve to the actual public URL (`https://domain.com/ua/...`). Therefore, `buildLanguageAlternatesMap()` maps the `uk` key directly to `LOCALE_METADATA.uk.urlPrefix` (`'/ua'`).

## 2. Unified SEO Core, Origin Hardening & Shared `OpenGraph` Builder

Origin validation lives in `resolvePublicSiteUrl()` inside `apps/web/src/shared/config/env.ts` (backed by Zod `HttpOriginSchema` and `parseSafeHttpOrigin()`, with a one-time production warning outside `WORKFOLIO_DEMO_MODE=true` if `NEXT_PUBLIC_SITE_URL` is missing or invalid). All URL, OpenGraph, and JSON-LD builders in `apps/web/src/shared/lib/seo.ts` consume `LOCALE_METADATA` and `resolvePublicSiteUrl()`:

```typescript title="apps/web/src/shared/lib/seo.ts"
export function buildLocalizedPath(pathname: string, locale: SupportedLocale = DEFAULT_LOCALE): string {
  const normalizedPath = normalizeSeoPathname(pathname)
  const prefix = LOCALE_METADATA[locale].urlPrefix

  if (normalizedPath === '/') {
    return prefix || '/'
  }
  return `${prefix}${normalizedPath}`
}

export function buildOpenGraphMetadata(input: OpenGraphMetadataInput): NonNullable<Metadata['openGraph']> {
  const base = {
    title: input.title,
    description: input.description,
    url: buildLocalizedUrl(input.pathname, input.locale),
    siteName: SITE_NAME,
    locale: resolveOgLocale(input.locale),
    alternateLocale: resolveAlternateOgLocales(input.locale),
  }

  if (input.type === 'article') {
    return {
      ...base,
      type: 'article',
      ...(input.publishedTime ? { publishedTime: input.publishedTime } : {}),
      ...(input.tags && input.tags.length > 0 ? { tags: [...input.tags] } : {}),
    }
  }

  return { ...base, type: input.type ?? 'website' }
}
```

### Why `buildOpenGraphMetadata()` Exists
Next.js performs a **shallow merge** on the `openGraph` object between `layout.tsx` and child route `page.tsx` files. Without a shared builder, overriding `openGraph` on `/cv`, `/system-status`, or `/knowledge-base/[...slug]` silently drops `siteName` and `alternateLocale`. `buildOpenGraphMetadata()` guarantees consistent `siteName`, `locale`, and `alternateLocale` across every route (`[locale]/layout.tsx`, `[locale]/cv/page.tsx`, `[locale]/system-status/page.tsx`, `[locale]/knowledge-base/page.tsx`, and `[locale]/knowledge-base/[...slug]/page.tsx`).

## 3. Hybrid Knowledge Base SEO (`sitemap.ts`, `robots.ts`) & Edge Proxy Hygiene

Because the Knowledge Base splits into public architectural blueprints (`/knowledge-base` + `/knowledge-base/this-project/**`) and Edge-JWT-protected study notes, crawler configuration strictly mirrors `PUBLIC_KB_ROOT_SEGMENTS = ['this-project']` so search engines encounter **zero `307` auth redirects**:

1. **Hybrid Sitemap Filtering (`apps/web/src/app/sitemap.ts`):**
   - Registers static hubs: `/` (`priority: 1.0`), `/cv` (`0.9`), `/knowledge-base` (`0.9`), and `/system-status` (`0.85`).
   - Walks `getAllStaticKnowledgeSlugArrays()` and skips every non-public route via `if (!isPublicKnowledgeBasePath(pathname)) continue`, emitting only `this-project/**` folders and articles with real `publishedAt` dates across `EN / UA / RU` (`alternates.languages`).
2. **Dynamic Protected Category Disallow (`apps/web/src/app/robots.ts`):**
   - `buildProtectedKbDisallowRules()` iterates `KnowledgeCategoryEnum.options` minus `PUBLIC_KB_ROOT_SEGMENTS` across all 3 locale prefixes (`''`, `'/ua'`, `'/ru'`), outputting `disallow: ['/api/', '/search-index/', ...buildProtectedKbDisallowRules()]`.
3. **Explicit Asset Extension Matcher (`apps/web/src/proxy.ts`):**
   - Metadata routes (`robots.ts`, `sitemap.ts`, `llms.txt/route.ts`, `icon.tsx`, `apple-icon.tsx`, `[locale]/opengraph-image.tsx`) bypass Edge Auth via an explicit static extension list (`ico|png|jpg|jpeg|gif|svg|webp|avif|pdf|css|js|mjs|map|woff|woff2|ttf|otf|txt|xml|json|webmanifest`) rather than a blanket `.*\..*` pattern.
4. **Soft-404 & Noindex Protection:**
   - Unmatched locale routes hit `app/[locale]/[...rest]/page.tsx` -> `notFound()` (strict HTTP `404` rendered by `app/[locale]/not-found.tsx`).
   - Inside `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx`, `export const dynamicParams = false` blocks arbitrary slugs at the router level, and the `generateMetadata()` fallback explicitly returns `robots: { index: false, follow: false }`.

## 4. XSS-Safe `JSON-LD` (`ProfilePage`, `TechArticle`, `BreadcrumbList`), Localized `OG` Cards & `/llms.txt`

### Hardened JSON-LD Serialization
`serializeSafeJsonLd()` escapes all five dangerous characters for inline `<script type="application/ld+json">` injection safety (`<`, `>`, `&`, `\u2028`, `\u2029`):

```typescript title="apps/web/src/shared/lib/seo.ts"
export function serializeSafeJsonLd(payload: Record<string, unknown>): string {
  return JSON.stringify(payload)
    .replace(/</g, '\\u003c')
    .replace(/>/g, '\\u003e')
    .replace(/&/g, '\\u0026')
    .replace(/\u2028/g, '\\u2028')
    .replace(/\u2029/g, '\\u2029')
}
```

- **Home (`/`) & Resume (`/cv`):** emit `ProfilePage` + `Person` (`buildProfilePageJsonLd()`).
- **Knowledge Base Articles (`/knowledge-base/[...slug]`):** emit both enhanced `TechArticle` (`mainEntityOfPage`, `publisher`, localized `image` pointing to `/opengraph-image`, `datePublished`, `dateModified`, `keywords`) via `buildTechArticleJsonLd()` **and** `BreadcrumbList` via `buildBreadcrumbListJsonLd()`.

### Localized OpenGraph Cards (`EN / UA / RU`) with `Inter` TTF & Offline Fallback
`apps/web/src/app/[locale]/opengraph-image.tsx` (`1200×630`, `generateStaticParams` over `SUPPORTED_LOCALES`) renders localized `Obsidian Editorial Dark` cards (`OG_LOCALE_COPY` for `en`, `uk`, `ru`):
- Fetches Cyrillic-capable `Inter` `.ttf` weights (`400`, `700`) from Google Fonts via `fetchGoogleFontTtf()` (`AbortSignal.timeout(4000)`) with module-level promise caching (`cachedInterFontsPromise`).
- **Resilient Offline Fallback:** if an offline or air-gapped build cannot download `Inter` TTF (`fonts.length === 0`), it automatically falls back to `OG_LOCALE_COPY.en` and `sans-serif` so Satori never renders tofu boxes (`□□□`).

### AI Discovery Manifest (`/llms.txt`)
`apps/web/src/app/llms.txt/route.ts` (`force-static`) serves a machine-readable Markdown dossier covering executive positioning, `/`, `/cv`, `/system-status`, `/knowledge-base/this-project`, commercial highlights, the 16 ADRs, and the Hybrid Knowledge Base catalog (explicitly marking protected study-note trees as Guest-Pass-gated and excluded from crawler indexation).
