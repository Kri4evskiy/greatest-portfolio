## 1. Verifying Optimization in React DevTools

Open **React DevTools → Components**: every component compiled successfully shows a **`Memo ✨`** pill next to its name. If the pill is missing, the compiler detected a side effect during render and safely skipped that component without breaking your app.

## 2. Escape Hatch Directives (`'use no memo'` & `'use memo'`)

```tsx title="Temporary Opt-Out for Mutable Legacy Libraries"
export function LegacyChartWrapper({ mutableInstance }: { mutableInstance: ExternalChart }) {
  'use no memo'
  // Compiler skips memoizing this component so external imperative mutations always reflect
  return <div data-chart-version={mutableInstance.version} />
}
```

| Directive / Mode | Effect | When to Use |
| :--- | :--- | :--- |
| Default (`infer` / `all`) | Compiles every valid component & hook | Greenfield Next.js 16 projects (our setup) |
| `'use no memo'` | Skips compiling a specific function | Debugging a suspect third-party mutation bug |
| `'use memo'` (`annotation` mode) | Opt-in compilation per component | Gradual migration of legacy 500k+ LOC codebases |
