# 🎨 Workfolio UI v2 — Мастер-спецификация редизайна (Editorial Craft × Linear Precision)

> **Статус:** Спецификация для **Приоритета №4** (после Live Deploy №1, Sentry/PostHog/Telegram №2 и Redis №3).
> **Цель:** Пересобрать визуальный язык, композицию и продуктовую навигацию (`discoverability`) так, чтобы сайт перестал ощущаться как «аккуратная шаблонная `shadcn/ui`-админка», перестал утомлять глаза десятками одинаковых рамок и бейджей, и стал запоминающимся авторским инженерным портфолио, по которому **хочется** кликать дальше.
> **Незыблемое ограничение:** 0 поломок бизнес-логики, роутинга `FSD-Modular`, SSG/SEO, `next-intl` (`EN/UK/RU`), `React 19 Compiler` и строгой политики безопасности (`CSP`, `Zero-Eval HAST`). Все 3 семантические палитры (`Warm Paper`, `Graphite`, `Sepia`) × `Light/Dark` сохраняются и дорабатываются.

## 1. Честный диагноз `UI v1` (почему «болят глаза», даже если цвета красивые)

Проблема текущей версии не в цветовых палитрах (они подобраны удачно для чтения), а в **композиционной усталости и отсутствии визуальной иерархии**:

1. **«Болезнь коробок и бейджей» (Border & Box Fatigue):**
   - На одном первом экране `WorkfolioHeroSection` рендерится ~45 прямоугольников с бордерами: 3 верхних бейджа + 4 рамочные кнопки контактов + 4 CTA-кнопки + 4 карточки Hard Skills с ~30 мелкими бейджами внутри + Callout с 3 вложенными карточками.
   - Когда всё обведено рамкой `rounded-xl border bg-card`, глаз не понимает, куда смотреть в первую секунду — нет главной доминанты и нет «воздуха».
2. **Узнаваемый «generic AI / shadcn» почерк:**
   - Одинаковые `Card` с `shadow-xs` на каждом блоке от верха до низа.
   - Иконка `lucide-react` приклеена к каждому заголовку (`GitBranch`, `Briefcase`, `Sparkles`, `Zap`).
   - В `ExperienceCard` зелёный щит `<ShieldCheck className="text-success" />` используется как маркер у **каждого** буллита опыта (выглядит как маркетинговый список тарифа SaaS, а не как взрослое резюме Senior-инженера).
3. **Хедер-тулбар вместо навигации:**
   - В `WorkfolioHeader` справа в одну линию втиснуто 7–8 рамочных кнопок (`Search`, `Theme`, `Lang`, `🔒 Base of Knowledge [Protected]`, `Logout`, `CV`, `ADR`). Навигация смешана с утилитами.
4. **Психологический барьер замка `🔒 Protected` в хедере:**
   - Первое, что видит занятый рекрутер или техлид в шапке — оранжевый бейдж «закрыто», хотя самые ценные 14 статей (`This Project`) полностью публичны. Интерфейс подсвечивает _ограничение_, а не _ценность_.
5. **Плоский монотонный скролл главной страницы:**
   - 5 тяжёлых одноколоночных секций подряд (`Hero + Skills + Pillars` ➔ `5 Case Studies` ➔ `Experience` ➔ `16-строчный Tech Radar` ➔ `9 карточек Roadmap`) с одинаковой плотностью и шагом `space-y-4`.
6. **Боязливая типографическая шкала и отсутствие акцента:**
   - Разница между `h2` секции (`text-xl`, 20px) и заголовком карточки (`text-lg`, 18px) — всего 2px. При беглом 5-секундном сканировании разделы сливаются.
   - Полная монохромность (`--primary` = почти чёрный/белый) лишает главные CTA визуального якоря.
7. **Скрытая инженерная мощь (проблема Discoverability):**
   - Рекрутер, пришедший по ссылке на `/cv`, скачивает PDF и закрывает вкладку, так и не узнав, что под капотом работают живой NestJS 12 API, SSE-стрим, `/system-status`, `Cmd+K` MiniSearch, 16 ADR, Telegram-бот и `/lab`.
   - На первом экране главной нет ни одного живого интерактивного артефакта — только текст.

## 2. Визуальное направление `UI v2`: _Editorial Craft × Linear Precision_

Мы сознательно **отказываемся** от вычурных 3D-шаров, тяжёлого WebGL, кислотных градиентов и параллакса (они вредят CWV, отвлекают от чтения и выглядят неуместно для Senior Full-Stack / Architecture профиля).

Наш ориентир — **журнальная швейцарская типографика + тактильная точность инженерного продукта**:

- **Референсы для калибровки вкуса:**
  - **Rauno Freiberg (`rauno.me`)** — эталон design engineering: hairline-линии (`1px`), безупречный воздух, физика микровзаимодействий, ощущение нативного macOS-приложения.
  - **Emil Kowalski (`emilkowal.ski`) & Paco Coursey (`paco.me`)** — редакционный минимализм, сильная типографика, спокойная уверенность без лишних декораций.
  - **Linear (`linear.app`) & Stripe Press / Stripe Docs** — тональные слои вместо тяжёлых теней, один выверенный акцентный цвет, кристально чистая навигация и уважение к длинному чтению.

### Ключевые правила системы

1. **Правило 70% «Border Diet» (диета рамок):**
   - Карточки с рамкой используются **только** для интерактивных островов, выделенных витрин и модалок.
   - Списки навыков, опыта, архива проектов и метаданных строятся на **типографике, выравнивании по сетке и волосяных линиях (`border-border/50`, `divide-y`)** — без «коробок в коробках».
2. **Уверенная типографическая шкала + Редакционная «изюминка»:**
   - Базовые шрифты остаются Zero-CLS (`next/font/google`, `latin + cyrillic`): `Inter` (UI/текст) + `JetBrains Mono` (метаданные, даты, нумерация `01 /`, код, метрики).
   - **Опциональный акцентный Editorial Serif с поддержкой кириллицы** (например, `Newsreader` или `Cormorant Garamond` / `Lora` — подключается только italic/400–500, минимум веса): используется **точечно** для 1–2 смысловых слов в `h1` Statement Hero или цитатах (_«Senior Full-Stack Engineer building **resilient** web systems»_). Один журнальный курсивный штрих мгновенно снимает ощущение шаблонного AI-сайта.
   - Контраст размеров:
     - `h1` Hero: `clamp(2.4rem, 5vw, 3.85rem)`, `tracking-[-0.035em]`, `leading-[1.06]`.
     - Заголовки секций `h2`: `text-2xl sm:text-3xl`, `tracking-[-0.025em]`, сверху тонкий моноширинный индекс `01 / ARCHITECTURE` (`text-[11px] uppercase tracking-[0.14em] text-muted-foreground`).
     - Увеличенный вертикальный ритм между секциями (`space-y-20 sm:space-y-28` вместо сжатых `space-y-12`).
3. **Один благородный фирменный акцент `--brand-accent` (до 5% площади экрана):**
   - Добавить токен `--brand-accent` / `--brand-accent-foreground` в `packages/ui/src/styles/theme.css` для всех 6 комбинаций (`Light/Dark × Warm Paper/Graphite/Sepia`), проверив контраст **WCAG AA (>= 4.5:1)**:
     - `Warm Paper`: глубокий терракотовый / архитектурный кобальт.
     - `Graphite`: чистый инженерный синий / индиго (в духе Linear).
     - `Sepia`: тёплый глубокий янтарь / бордо.
   - Используется **строго дозированно**: главный CTA, активная навигационная метка, фокус-кольцо, живой акцент в Bento-карточке.
4. **Анти-AI гигиена иконок:**
   - Убрать декоративные иконки из заголовков секций `h2` (`<GitBranch />`, `<Briefcase />`).
   - Полностью убрать `<ShieldCheck />` из буллитов опыта — заменить на чистое длинное тире `—` или лаконичную точку с акцентированием цифр (`font-medium text-foreground`).
   - Иконки `lucide-react` (14–16px, `strokeWidth={1.75}`) остаются **только там, где они несут функцию**: кнопки действий, навигационные стрелки `↗`, поиск, статус замка/сети, тултипы.

## 3. Архитектура страниц и 5 фирменных «изюминок» (чтобы хотелось кликать дальше)

### A. Новый 3-зонный Хедер (`WorkfolioHeader` — воздух вместо тулбара)

Убираем 7 рамочных кнопок и оранжевый замок из шапки:

- **Левая зона:** лаконичная монограмма `SK` + имя (на мобилке только `SK` + короткое имя).
- **Центральная зона (чистая текстовая навигация без бордеров, с тонкой активной полоской снизу):**
  - `Overview` (`/`)
  - `Knowledge Base` (`/knowledge-base`) — **без оранжевого замка и без бейджа `[Protected]`!** Гость спокойно заходит, читает публичный `This Project`, а мягкий Soft-Lock встречает его уже внутри защищённых веток.
  - `CV` (`/cv`)
  - `Live Status` (`/system-status`) — с микроскопической пульсирующей зелёной точкой `6px` прямо рядом с текстом (мгновенно вызывает любопытство: _«О, там что-то живое работает?»_).
  - `Lab` (`/lab`, добавится вместе с лабораторией в том же Приоритете №4).
- **Правая зона (компактная группа утилит):**
  - Иконка-капсула `⌘K` (поиск), `ThemeToggle`, `LanguageSwitcher`, и при активной сессии — аккуратный компактный pill пользователя (`USER` / `ADMIN` + Logout в Popover).
- **Мобильная версия (`360px`):** чистый нижний или выдвижной nav-sheet вместо сжатой каши кнопок.

### B. Асимметричный 2-колоночный Hero + Изюминка №1: «Live System Bento Card»

Вместо длинной вертикальной стопки из 45 коробок — **сильная 2-колоночная композиция** (`lg:grid-cols-[1.25fr_0.95fr] lg:items-start lg:gap-12`):

- **Левая колонка (Statement Hero):**
  1. Тонкая статус-строка без тяжёлой рамки: зелёная пульсирующая точка + `Available for Senior Frontend / Full-Stack roles · Kyiv / Remote · 5+ yrs`.
  2. Крупный `h1` с журнальным акцентом + спокойная 2-строчная позиция (написана как введение к книге, а не как сухой список ключевых слов).
  3. **Ровно 2 главных CTA:** основной (`Explore Architecture` / `View CV`) и вторичный ghost/outline.
  4. Под кнопками — тихая текстовая строка прямых контактов (`Telegram ↗ · LinkedIn ↗ · GitHub ↗ · Email ↗`) без 4 коробок.
- **Правая колонка — «Live System Bento Card» (главная визуальная изюминка первого экрана!):**
  - Одна безупречно собранная тональная панель (`rounded-2xl border border-border/80 bg-surface-subtle/60 p-5`) с hairline-разделителями внутри:
    - **Верхняя строка:** живой статус системы (`● API & SSE Live` / latency / режим `Production`), клик ведёт на `/system-status`.
    - **Встроенный быстрый запуск `⌘K`:** кликабельная строка поиска _«Search 32+ notes, 16 ADRs, #tags…»_ — сразу открывает MiniSearch.
    - **«Explore Under the Hood» (3–4 нативные «двери» с мягким hover-сдвигом стрелки `↗`):**
      - `This Project · 14 Deep-Dives` (открыто без логина)
      - `CV / Resume · PDF + ATS`
      - `Interactive Lab · XYFlow & Sandboxes` (когда выйдет `/lab`)
      - `Telegram Bot · Get CV & Welcome` (когда выйдет Telegram Фаза 2)
  - **Почему это работает:** человек с первой секунды видит, что перед ним живой инженерный продукт, и сам хочет кликнуть в `/system-status`, `⌘K` или `This Project`.

### C. Секции главной страницы (ритм, контраст и сокращение «простыни»)

Главная должна сканироваться за **30–45 секунд**, а глубокие детали открываться по клику:

1. **`01 / CAPABILITIES` (вместо 4 коробок с 30 бейджами):**
   - Чистая **Hairline Skills Table** (`divide-y border-y border-border/60`): 4 аккуратные строки (`Frontend`, `Backend`, `Data & Infra`, `Quality & DX`), слева моноширинная метка, справа технологии через тонкий разделитель `·`. Читается мгновенно, 0 визуального шума!
2. **`02 / SELECTED ARCHITECTURE` (Editorial Work Archive вместо 5 одинаковых карточек):**
   - **1 флагманский wide-блок** (`This Project — Full-Stack Monorepo & MDX Engine`) с визуальным мини-превью/метриками.
   - Под ним — **интерактивный редакционный список** остальных ключевых кейсов (строка на всю ширину с hairline-разделителем: `Название` + `Ключевая метрика` + `2–3 тега текстом` + `↗`). На hover строка мягко меняет тон поверхности, а стрелка уезжает вправо-вверх.
3. **`03 / EXPERIENCE` (2-колоночный редакционный таймлайн):**
   - Левая колонка (`md:w-44 shrink-0`): годы моноширинным (`2024 — 2026`) + домен (`FinTech / Enterprise`).
   - Правая колонка: компания, роль, спокойный список 3–4 сильных буллитов с тире `—` (без `<ShieldCheck />`), стек в 1 спокойную моноширинную строку внизу.
   - Ранний опыт аккуратно сворачивается в `Collapsible`, а образование и языки идут компактной 2-колоночной сноской с hairline-линией.
4. **`04 / TECH RADAR (16 ADR)` & `05 / ROADMAP`:**
   - **Tech Radar:** чище шапка таблицы, меньше визуальной тяжести у фильтров (текстовые табы с подчёркиванием вместо 6 жирных обведённых кнопок), клик по строке открывает аккуратный Drawer/Sheet или Dialog с ADR.
   - **Engineering Roadmap:** вместо 9 развёрнутых карточек в сетке — компактный **табовый/списочный вид** (`Planned Next` / `In Progress` / `Evaluating` / `Shipped`), где по умолчанию видны только 3–4 актуальных приоритета, а детали аргументов раскрываются плавным `Collapsible`.

### D. Feature Discoverability на странице `/cv` (для рекрутеров по прямой ссылке)

- Опциональный лёгкий **Audience Lens** (или ненавязчивая подсказка-тур на 60 сек) для быстрого переключения акцента «For Recruiters» / «For Tech Leads».

### E. Изюминка Футера: Дизайнерский «Colophon»

В стиле лучших портфолио design-инженеров (Rauno / Paco / Stripe):

- Верхняя строка: контакты и быстрый доступ к CV.
- Нижняя строка (**Colophon**):
  - _Typography:_ `Inter · JetBrains Mono` (+ serif),
  - _Interactive Palette Swatches:_ 3 мини-кружка палитр (`Warm Paper / Graphite / Sepia`) прямо в футере — можно потыкать и мгновенно переключить настроение сайта,
  - _System:_ версия релиза (`v0.x`), стек и живой `FooterSseStatus` с переходом на `/system-status`.

## 4. Тактильные микровзаимодействия и примитивы React 19.2+ / CSS

Никаких тяжёлых JS-анимаций, ломающих INP или бандл — только нативный CSS + лёгкие примитивы:

1. **Тонкая физика клика и ховера:** `active:scale-[0.985]` на кнопках, плавный `transition-transform` стрелок `↗` / `→`, скользящий тональный hover на строках списков.
2. **Опциональный subtle spotlight** (1 флагманская карточка / Bento Card): CSS-переменные `--mx`/`--my` через `onPointerMove` (обновление стиля через `ref`, **0 ререндеров React!**) для едва заметного мягкого свечения бордера в тёмной теме (как в Linear).
3. **Современные примитивы React 19.2+ & CSS Platform:**
   - `<Activity mode={...}>` — сохранение состояния скрытых табов (`/cv`, `/lab`, Roadmap) без размонтирования.
   - `useEffectEvent` — чтение актуальных значений внутри эффектов без лишних переподписок.
   - Опциональный `<ViewTransition>` — плавный переход при открытии статьи из каталога Базы Знаний или переключении фильтров.
   - Строгий `@media (prefers-reduced-motion: reduce)` — мгновенные переходы для пользователей с чувствительностью к движению.
