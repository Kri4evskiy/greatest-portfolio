## 1. Миграция с pnpm 10 на pnpm 12 (Rust-ядро + SQLite-стор)

В pnpm 12 устаревшее поле onlyBuiltDependencies в package.json полностью удалено. Все разрешения на выполнение скриптов сборки перенесены в строгий словарь allowBuilds внутри pnpm-workspace.yaml, иначе срабатывает защита ERR_PNPM_IGNORED_BUILDS.

```yaml
packages:
  - "apps/*"
  - "packages/*"

allowBuilds:
  "@biomejs/biome": true
  "@parcel/watcher": true
  "@prisma/client": true
  "@prisma/engines": true
  "@swc/core": true
  esbuild: true
  lefthook: true
  prisma: true
  sharp: true
```

## 2. Единый BuildKit Cache Mount для всех 3 сервисов

Чтобы контейнеры web, api и telemetry-ms не скачивали одни и те же 100+ МБ нативных пакетов с нуля, мы подключили общий кэш-маунт BuildKit и прогрев бинарника pnpm в кэшируемом слое builder:

```dockerfile
RUN corepack enable && corepack prepare pnpm@12.16.1 --activate && pnpm --version
RUN --mount=type=cache,id=pnpm,target=/root/.local/share/pnpm/store \
    pnpm install --frozen-lockfile --ignore-scripts
```

## 3. Очистка devDependencies с сохранением Prisma Client

Вызов pnpm prune --prod --ignore-scripts после сборки вычищает Biome, Turbo, TypeScript и Prisma CLI (~180 МБ) из финальных продакшен-образов, сохраняя сгенерированный рантайм-клиент .prisma/client:

- Сжатый образ telemetry-ms: 64.3 MB
- Сжатый образ api: 78.2 MB (подключение к PostgreSQL за 15 мс)
- Сжатый образ web (standalone): 85.6 MB
