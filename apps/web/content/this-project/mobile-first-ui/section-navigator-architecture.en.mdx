## 1. Solving Repeated Hash-Click Stalls in Next.js App Router

Standard Next.js `<Link href="/#projects">` components skip scrolling if `window.location.hash` already equals `#projects` after the user manually scrolls up.

### Direct Programmatic Scroll + Passive ScrollSpy

Our custom `useSectionNavigation` hook intercepts same-page clicks and triggers native smooth scrolling every single time:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const element = document.getElementById(sectionId)
if (element) {
  element.scrollIntoView({ behavior: 'smooth', block: 'start' })
  window.history.replaceState(null, '', `#${sectionId}`)
}
```

> [!NOTE]
> Active section tracking (`useActiveWorkfolioSection`) uses a `{ passive: true }` scroll listener throttled with `requestAnimationFrame`, guaranteeing **60 FPS** scrolling without main-thread layout thrashing.

## 2. Adaptive Surfaces Across Viewport Breakpoints

Moving the 4 CV section links out of `WorkfolioHeader` unlocked clean responsive behavior across every viewport width.
