## 1. Трирівнева матриця локалей (`LOCALE_METADATA` як Single Source of Truth)

Головна особливість мультимовного SEO в монорепозиторії полягає в тому, що внутрішній код мови, публічний URL-префікс, тег BCP 47 та стандарти пошукових роботів / месенджерів підпорядковуються різним специфікаціям.

Замість дублювання словників по фронтенду єдине джерело правди `LOCALE_METADATA` експортується з `packages/shared-schemas/src/locale.schema.ts` і використовується в `apps/web/src/shared/lib/seo.ts`, `robots.ts` та `apps/web/src/shared/i18n/routing.ts` (`localePrefix: { mode: 'as-needed', prefixes: { uk: '/ua' } }`):

| Мова | Внутрішній тип (`SupportedLocale` та суфікс `.mdx`) | Публічний URL-префікс (`urlPrefix`) | Пошуковий стандарт ISO 639-1 (`<html lang>` і `hreflang`) | Стандарт месенджерів (`ogLocale`) |
| :--- | :--- | :--- | :--- | :--- |
| **English (Default)** | `'en'` (`*.en.mdx`) | `''` (`/`, `/cv`, `/system-status`, `/knowledge-base`) | `en` (+ `x-default`) | `en_US` |
| **Українська** | `'uk'` (`*.uk.mdx`) | `'/ua'` (`/ua`, `/ua/cv`, `/ua/system-status`, `/ua/knowledge-base`) | `uk` | `uk_UA` |
| **Русский** | `'ru'` (`*.ru.mdx`) | `'/ru'` (`/ru`, `/ru/cv`, `/ru/system-status`, `/ru/knowledge-base`) | `ru` | `ru_RU` |

> [!IMPORTANT]
> За специфікацією Google Search Central атрибут `hreflang` зобов’язаний використовувати код мови за стандартом **ISO 639-1** (`uk` для української мови, а не код країни `ua`), але сам `href` має вказувати на реальний публічний URL (`https://domain.com/ua/...`). Тому `buildLanguageAlternatesMap()` пов’язує ключ `uk` напряму з `LOCALE_METADATA.uk.urlPrefix` (`'/ua'`).

## 2. Єдине SEO-ядро, валідація Origin і спільний білдер `OpenGraph`

Валідація `NEXT_PUBLIC_SITE_URL` винесена в `resolvePublicSiteUrl()` усередині `apps/web/src/shared/config/env.ts` (через Zod-схему `HttpOriginSchema` і `parseSafeHttpOrigin()`, з одноразовим попередженням у продакшені поза `WORKFOLIO_DEMO_MODE=true`). Усі хелпери в `apps/web/src/shared/lib/seo.ts` спираються на `LOCALE_METADATA` та `resolvePublicSiteUrl()`:

```typescript title="apps/web/src/shared/lib/seo.ts"
export function buildLocalizedPath(pathname: string, locale: SupportedLocale = DEFAULT_LOCALE): string {
  const normalizedPath = normalizeSeoPathname(pathname)
  const prefix = LOCALE_METADATA[locale].urlPrefix

  if (normalizedPath === '/') {
    return prefix || '/'
  }
  return `${prefix}${normalizedPath}`
}

export function buildOpenGraphMetadata(input: OpenGraphMetadataInput): NonNullable<Metadata['openGraph']> {
  const base = {
    title: input.title,
    description: input.description,
    url: buildLocalizedUrl(input.pathname, input.locale),
    siteName: SITE_NAME,
    locale: resolveOgLocale(input.locale),
    alternateLocale: resolveAlternateOgLocales(input.locale),
  }

  if (input.type === 'article') {
    return {
      ...base,
      type: 'article',
      ...(input.publishedTime ? { publishedTime: input.publishedTime } : {}),
      ...(input.tags && input.tags.length > 0 ? { tags: [...input.tags] } : {}),
    }
  }

  return { ...base, type: input.type ?? 'website' }
}
```

### Навіщо потрібен єдиний `buildOpenGraphMetadata()`
Next.js виконує **поверхневе злиття (shallow merge)** об’єкта `openGraph` між `layout.tsx` і дочірніми `page.tsx`. Без спільного білдера перевизначення `openGraph` на `/cv`, `/system-status` або `/knowledge-base/[...slug]` мовчки втрачало б `siteName` і `alternateLocale`. `buildOpenGraphMetadata()` гарантує консистентні `siteName`, `locale` та `alternateLocale` на кожному маршруті (`[locale]/layout.tsx`, `[locale]/cv/page.tsx`, `[locale]/system-status/page.tsx`, `[locale]/knowledge-base/page.tsx`, `[locale]/knowledge-base/[...slug]/page.tsx`).

## 3. Гібридне SEO Бази Знань (`sitemap.ts`, `robots.ts`) та гігієна Edge Proxy

Оскільки База Знань розділена на публічний архітектурний blueprint (`/knowledge-base` + `/knowledge-base/this-project/**`) і захищені Edge JWT конспекти, правила для пошукових роботів суворо дзеркалять `PUBLIC_KB_ROOT_SEGMENTS = ['this-project']`, забезпечуючи **нуль `307`-редиректів для краулерів**:

1. **Гібридна фільтрація Sitemap (`apps/web/src/app/sitemap.ts`):**
   - Включає кореневі хаби: `/` (`priority: 1.0`), `/cv` (`0.9`), `/knowledge-base` (`0.9`) та `/system-status` (`0.85`).
   - Під час обходу `getAllStaticKnowledgeSlugArrays()` пропускає захищені гілки через `if (!isPublicKnowledgeBasePath(pathname)) continue`, додаючи до `sitemap.xml` лише розділи й статті `this-project/**` із реальними датами `publishedAt` для `EN / UA / RU` (`alternates.languages`).
2. **Динамічна заборона захищених категорій (`apps/web/src/app/robots.ts`):**
   - `buildProtectedKbDisallowRules()` бере `KnowledgeCategoryEnum.options` за винятком `PUBLIC_KB_ROOT_SEGMENTS` і генерує правила заборони для всіх 3 префіксів локалей (`''`, `'/ua'`, `'/ru'`), віддаючи `disallow: ['/api/', '/search-index/', ...buildProtectedKbDisallowRules()]`.
3. **Явний matcher розширень статики (`apps/web/src/proxy.ts`):**
   - Мета-маршрути (`robots.ts`, `sitemap.ts`, `llms.txt/route.ts`, `icon.tsx`, `apple-icon.tsx`, `[locale]/opengraph-image.tsx`) оминають Edge Auth завдяки явному переліку розширень (`ico|png|jpg|jpeg|gif|svg|webp|avif|pdf|css|js|mjs|map|woff|woff2|ttf|otf|txt|xml|json|webmanifest`) замість широкого `.*\..*`.
4. **Захист від Soft-404 та `noindex`:**
   - Неіснуючі маршрути всередині локалі потрапляють у `app/[locale]/[...rest]/page.tsx` -> `notFound()` (чесний HTTP `404` через `app/[locale]/not-found.tsx`).
   - У `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx` директива `export const dynamicParams = false` відсікає невідомі слаги, а fallback-гілка `generateMetadata()` явно повертає `robots: { index: false, follow: false }`.

## 4. XSS-безпечний `JSON-LD` (`ProfilePage`, `TechArticle`, `BreadcrumbList`), локалізовані `OG`-картки та `/llms.txt`

### Загартована серіалізація JSON-LD
Хелпер `serializeSafeJsonLd()` екранує всі 5 небезпечних символів для безпечного вбудовування в `<script type="application/ld+json">` (`<`, `>`, `&`, `\u2028`, `\u2029`):

```typescript title="apps/web/src/shared/lib/seo.ts"
export function serializeSafeJsonLd(payload: Record<string, unknown>): string {
  return JSON.stringify(payload)
    .replace(/</g, '\\u003c')
    .replace(/>/g, '\\u003e')
    .replace(/&/g, '\\u0026')
    .replace(/\u2028/g, '\\u2028')
    .replace(/\u2029/g, '\\u2029')
}
```

- **Головна (`/`) і Резюме (`/cv`):** рендерять `ProfilePage` + `Person` (`buildProfilePageJsonLd()`).
- **Статті Бази Знань (`/knowledge-base/[...slug]`):** рендерять одночасно розширений `TechArticle` (`mainEntityOfPage`, `publisher`, локалізований `image` на `/opengraph-image`, `datePublished`, `dateModified`, `keywords`) через `buildTechArticleJsonLd()` **та** навігаційний ланцюжок `BreadcrumbList` через `buildBreadcrumbListJsonLd()`.

### Локалізовані OpenGraph-картки (`EN / UA / RU`) з `Inter` TTF і офлайн-фолбеком
`apps/web/src/app/[locale]/opengraph-image.tsx` (`1200×630`, `generateStaticParams` по `SUPPORTED_LOCALES`) генерує локалізовані банери `Obsidian Editorial Dark` (`OG_LOCALE_COPY` для `en`, `uk`, `ru`):
- Завантажує кириличні TTF-накреслення `Inter` (`400`, `700`) з Google Fonts через `fetchGoogleFontTtf()` (`AbortSignal.timeout(4000)`) із кешуванням промісу на рівні модуля (`cachedInterFontsPromise`).
- **Офлайн-фолбек:** якщо в ізольованій збірці без мережі не вдалося отримати TTF (`fonts.length === 0`), генератор автоматично перемикається на `OG_LOCALE_COPY.en` та `sans-serif`, щоб Satori ніколи не малював «тофу»-квадрати (`□□□`).

### AI-маніфест `/llms.txt`
`apps/web/src/app/llms.txt/route.ts` (`force-static`) формує машиночитаний Markdown-паспорт портфоліо з посиланнями на `/`, `/cv`, `/system-status`, `/knowledge-base/this-project`, комерційним досвідом, 16 ADR і структурою гібридної Бази Знань (явно позначаючи захищені категорії як закриті Guest Pass та виключені з індексації).

## 5. Архітектурний реєстр SEO-підсистеми

| Компонент SEO | Файл / Розташування | Призначення в продакшені |
| :--- | :--- | :--- |
| **Матриця метаданих локалей** | `packages/shared-schemas/src/locale.schema.ts` | Єдиний контракт `LOCALE_METADATA` (`code`, `urlPrefix`, `intlLocale`, `ogLocale`) |
| **Валідація Origin із Env** | `apps/web/src/shared/config/env.ts` | `resolvePublicSiteUrl()` через Zod `HttpOriginSchema` + попередження в продакшені |
| **SEO-ядро та JSON-LD** | `apps/web/src/shared/lib/seo.ts` | `buildPageAlternates`, `buildOpenGraphMetadata` (`siteName` + `alternateLocale`), `serializeSafeJsonLd`, `ProfilePage`, розширений `TechArticle`, `BreadcrumbList` |
| **Adaptive Viewport і GoogleBot** | `apps/web/src/app/[locale]/layout.tsx` | Системний `themeColor` (`#FAF8F5` / `#121211`), `authors`/`creator`, `max-image-preview: 'large'` |
| **Robots.txt Generator** | `apps/web/src/app/robots.ts` | Закриває `/api/`, `/search-index/` і всі захищені категорії БЗ у всіх префіксах (`''`, `/ua`, `/ru`) |
| **Гібридний Sitemap.xml** | `apps/web/src/app/sitemap.ts` | Статичні хаби (`/`, `/cv`, `/knowledge-base`, `/system-status`) + лише публічна `this-project/**` (нуль `307`) |
| **AI-маніфест (`/llms.txt`)** | `apps/web/src/app/llms.txt/route.ts` | Структурований Markdown-паспорт досвіду, 16 ADR та каталогу БЗ для AI-пошуковиків |
| **Локалізований OpenGraph (`1200×630`)** | `apps/web/src/app/[locale]/opengraph-image.tsx` | Локалізовані картки `EN / UA / RU` через `next/og`, `Inter` TTF (`400`/`700`) та офлайн-фолбек на EN |
| **Суворий HTTP 404 і Noindex** | `app/[locale]/[...rest]/page.tsx`, `not-found.tsx`, `knowledge-base/[...slug]/page.tsx` | Чесний HTTP `404`, `dynamicParams = false` та `robots: { index: false, follow: false }` для 404-метаданих |
