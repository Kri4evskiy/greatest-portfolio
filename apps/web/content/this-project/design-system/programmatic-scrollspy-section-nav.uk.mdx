## 1. Детермінований `#hash`-скрол у Next.js App Router

Стандартний роутер Next.js (`<Link href="/#projects">`) пропускає прокрутку, якщо в адресному рядку вже стоїть `#projects`, а користувач прокрутив сторінку вгору колесом миші та клікнув по посиланню повторно.

Щоб навігація по секціях працювала безвідмовно, хук `useSectionNavigation` розділяє міжсторінковий перехід (`router.push`) і внутрішньосторінковий програмний скрол:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const scrollToSection = useCallback(
  (sectionId: WorkfolioSectionId) => {
    if (pathname !== '/') {
      router.push(`/#${sectionId}`)
      return
    }

    const element = document.getElementById(sectionId)
    if (element) {
      element.scrollIntoView({ behavior: 'smooth', block: 'start' })
      window.history.replaceState(null, '', `#${sectionId}`)
    }
  },
  [pathname, router],
)
```

Кожна цільова секція головної сторінки розмічена класом `scroll-mt-20`, щоб фіксована верхня шапка (`h-14`) ніколи не перекривала заголовок блоку після зупинки скролу.

## 2. Пасивний `ScrollSpy` на `requestAnimationFrame` (`60 FPS`)

Для відстеження поточної секції на довгих сторінках використовується пасивний слухач прокрутки, синхронізований із частотою оновлення екрана через `requestAnimationFrame`:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
useEffect(() => {
  let rafId: number | null = null

  const updateActiveSection = () => {
    rafId = null
    const triggerLine = window.innerHeight * 0.28
    let currentSection: WorkfolioSectionId = WORKFOLIO_SECTION_IDS[0]

    for (const id of WORKFOLIO_SECTION_IDS) {
      const el = document.getElementById(id)
      if (!el) continue
      if (el.getBoundingClientRect().top <= triggerLine) {
        currentSection = id
      }
    }
    setActiveSection((prev) => (prev === currentSection ? prev : currentSection))
  }

  const onScroll = () => {
    if (rafId === null) {
      rafId = window.requestAnimationFrame(updateActiveSection)
    }
  }

  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

## 3. Ергономіка `PageSectionNavigator` (`< xl` проти `xl+`)

Замість перевантаження верхньої шапки `WorkfolioHeader` списком якірних посилань навігація по секціях винесена в окремий адаптивний вузол `PageSectionNavigator`:

| Брейкпоінт | Форм-фактор | Інженерна деталь |
| :--- | :--- | :--- |
| **Десктоп (`xl+`)** | Паруючий вертикальний індикатор праворуч (`right-5 top-1/2`) | Показує прогрес читання та розгортає підписи секцій при наведенні |
| **Мобільні та планшети (`< xl`)** | Плаваюча кнопка-пігулка в правому нижньому куті (`bottom-4 right-4`) | Розташована в природній зоні великого пальця; у `WorkfolioFooter` задано `pb-20 xl:pb-10`, щоб кнопка не перекривала копірайт і статус SSE |
