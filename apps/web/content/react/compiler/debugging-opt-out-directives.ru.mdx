## 1. Проверка плашки `Memo ✨` в React DevTools

Откройте вкладку **Components** в **React DevTools**: рядом с каждым оптимизированным компонентом светится бейдж **`Memo ✨`**. Если на конкретном компоненте бейджа нет — значит, компилятор обнаружил небезопасную мутацию в рендере и аккуратно пропустил его без поломки приложения.

## 2. Директивы управления `'use no memo'` и `'use memo'`

```tsx title="Точечное отключение компилятора для мутабельного SDK"
export function LegacyChartWrapper({ mutableInstance }: { mutableInstance: ExternalChart }) {
  'use no memo'
  // Компилятор не кэширует JSX этой функции, если сторонняя библиотека мутирует объект на месте
  return <div data-chart-version={mutableInstance.version} />
}
```

| Режим / Директива | Как работает | Где применять |
| :--- | :--- | :--- |
| По умолчанию (`all`) | Компилирует все чистые компоненты и хуки | Новые проекты на Next.js 16 (наша конфигурация) |
| `'use no memo'` | Исключает одну конкретную функцию | Быстрая диагностика бага со сторонней библиотекой |
| `'use memo'` (`annotation`) | Компилирует только помеченные функции | Пошаговый переезд больших legacy-кодовых баз |
