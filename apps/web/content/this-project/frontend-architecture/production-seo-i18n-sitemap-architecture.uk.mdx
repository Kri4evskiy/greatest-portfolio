## 1. Трирівнева матриця локалей (`Internal Code` vs `URL Prefix` vs `Hreflang / OpenGraph`)

Головна особливість мультимовного SEO в нашому проєкті полягає в тому, що внутрішній код мови, публічний префікс в адресній стрічці браузера та стандартні коди для пошукових роботів Google / месенджерів (Telegram, LinkedIn, Slack) підпорядковуються різним специфікаціям.

У `apps/web/src/shared/i18n/routing.ts` увімкнено режим `localePrefix: { mode: 'as-needed', prefixes: { uk: '/ua' } }`. Щоб на жодній сторінці не виникало розбіжностей, модуль `apps/web/src/shared/lib/seo.ts` чітко розділяє ці представлення:

| Мова | Внутрішній тип (`SupportedLocale` та суфікс `.mdx`) | Публічний URL-префікс (`as-needed`) | Пошуковий стандарт ISO 639-1 (`<html lang>` і `hreflang`) | Стандарт месенджерів (`og:locale`) |
| :--- | :--- | :--- | :--- | :--- |
| **English (Default)** | `'en'` (`*.en.mdx`) | Без префікса (`/`, `/cv`, `/knowledge-base`) | `en` (+ `x-default`) | `en_US` |
| **Українська** | `'uk'` (`*.uk.mdx`) | `/ua` (`/ua`, `/ua/cv`, `/ua/knowledge-base`) | `uk` | `uk_UA` |
| **Русский** | `'ru'` (`*.ru.mdx`) | `/ru` (`/ru`, `/ru/cv`, `/ru/knowledge-base`) | `ru` | `ru_RU` |

> [!IMPORTANT]
> За специфікацією Google Search Central атрибут `hreflang` зобов’язаний використовувати код мови за стандартом **ISO 639-1** (`uk` для української мови, а не код країни `ua`), але сам `href` усередині цього тегу має вказувати на реальний публічний маршрут сайту (`https://domain.com/ua/...`). Саме тому в `buildLanguageAlternatesMap()` ключ словника — `uk`, а згенерований URL веде на префікс `/ua`.

## 2. Єдине SEO-ядро та захист від невалідного Origin (`apps/web/src/shared/lib/seo.ts`)

Усі SEO-обчислення винесені в чисті серверні функції без зовнішніх залежностей:

```typescript title="apps/web/src/shared/lib/seo.ts"
const DEFAULT_SITE_URL = 'http://localhost:3000'

const LOCALE_URL_PREFIX_MAP: Record<SupportedLocale, string> = {
  en: '',
  uk: '/ua',
  ru: '/ru',
}

const OG_LOCALE_MAP: Record<SupportedLocale, string> = {
  en: 'en_US',
  uk: 'uk_UA',
  ru: 'ru_RU',
}

export function resolveSiteUrl(): string {
  const raw = process.env.NEXT_PUBLIC_SITE_URL?.trim()
  if (!raw) return DEFAULT_SITE_URL

  try {
    const parsed = new URL(raw)
    if (parsed.protocol !== 'http:' && parsed.protocol !== 'https:') {
      return DEFAULT_SITE_URL
    }
    return parsed.origin
  } catch {
    return DEFAULT_SITE_URL
  }
}
```

### Чому `resolveSiteUrl()` повертає `parsed.origin` через `new URL(raw)`?
У `apps/web/src/app/[locale]/layout.tsx` викликається `metadataBase: new URL(resolveSiteUrl())`. Якщо у змінній оточення `NEXT_PUBLIC_SITE_URL` на хостингу випадково опиниться рядок без протоколу, із зайвим слешем або шляхом (наприклад, `example.com/`), пряме створення `new URL()` без `try/catch` зламає збірку `next build`, а некоректний протокол може порушити цілісність `<link rel="canonical">`. Валідація через `parsed.origin` гарантує чистий `https://domain.com` або безпечний відкат на `http://localhost:3000`.

## 3. Генерація `canonical`, `alternates.languages` (`hreflang`) та `openGraph`

Функція `buildPageAlternates(pathname, locale)` викликається всередині `generateMetadata()` на всіх рівнях маршрутизації (`[locale]/layout.tsx`, `[locale]/cv/page.tsx`, `[locale]/knowledge-base/page.tsx` та `[locale]/knowledge-base/[...slug]/page.tsx`):

```typescript title="apps/web/src/shared/lib/seo.ts"
export function buildLanguageAlternatesMap(pathname: string): Record<string, string> {
  return {
    en: buildLocalizedUrl(pathname, 'en'),
    uk: buildLocalizedUrl(pathname, 'uk'),
    ru: buildLocalizedUrl(pathname, 'ru'),
    'x-default': buildLocalizedUrl(pathname, DEFAULT_LOCALE),
  }
}

export function buildPageAlternates(pathname: string, locale: SupportedLocale = DEFAULT_LOCALE) {
  return {
    canonical: buildLocalizedUrl(pathname, locale),
    languages: buildLanguageAlternatesMap(pathname),
  }
}
```

На основі цього об’єкта Next.js 16 автоматично рендерить у `<head>`:
- **`<link rel="canonical">`** — авторитетний URL поточної локалі (захищає від дублів в індексі за наявності query-параметрів на кшталт `?unlock=knowledge-base`).
- **Зв’язку `<link rel="alternate" hreflang="en | uk | ru | x-default">`** — перехресні посилання на всі мовні версії сторінки згідно з матрицею з Розділу 1 (`x-default` вказує на дефолтну англійську версію без префікса).
- **Мета-теги `openGraph` (`og:title`, `og:description`, `og:url`, `og:locale`, `og:type`, `og:image`)** — локалізовані картки Rich Link Preview для **Telegram, LinkedIn, Slack та Discord** (для статей Бази Знань також додаються `og:type="article"`, `article:published_time` та `article:tag`).

## 4. File-Based Metadata (`robots.ts`, `sitemap.ts`, `opengraph-image.tsx`, `icon.tsx`) та Edge Proxy

Усі мета-маршрути в `apps/web/src/app/` компілюються на етапі збірки (`SSG`, `0 КБ` клієнтського JS) та оминають перевірки JWT у `apps/web/src/proxy.ts` завдяки регулярному виразу `matcher`:

```typescript title="apps/web/src/proxy.ts"
export const config = {
  matcher: ['/((?!api|search-index|icon|apple-icon|_next|_vercel|.*opengraph-image.*|.*\\..*).*)'],
}
```

1. **Ізоляція службових ендпоінтів у `robots.ts`:** правило `disallow: ['/api/', '/search-index/']` закриває від пошукових краулерів REST/SSE-потоки бекенду (`/api/telemetry/stream`) та сирі JSON-індекси модалки `Cmd+K`.
2. **Автоматичний обхід дерева `.mdx` у `sitemap.ts`:** об’єднує кореневі хаби (`/`, `/cv`, `/knowledge-base`) з усіма шляхами з `getAllStaticKnowledgeSlugArrays()` та реальними датами `publishedAt` із `getAllKnowledgeFrontmatters(DEFAULT_LOCALE)`.
3. **Кодогенерація графіки через `next/og` (`ImageResponse` / Satori):**
   - `apps/web/src/app/icon.tsx` (`32×32`) та `apple-icon.tsx` (`180×180`) генерують обсидіанову іконку термінала `>_`.
   - `apps/web/src/app/[locale]/opengraph-image.tsx` (`1200×630`) рендерить фірмовий банер `Obsidian Editorial Dark` для кожної локалі (`generateStaticParams`) без зовнішніх мережевих запитів за шрифтами, а в `layout.tsx` увімкнено директиву `googleBot: { 'max-image-preview': 'large' }` та адаптивний `viewport.themeColor` (`#FAF8F5` / `#121211`) для мобільних шторок Safari та Chrome.
   - **Запобігання Soft-404 в індексі:** для будь-яких неіснуючих URL усередині локалі catch-all маршрут `app/[locale]/[...rest]/page.tsx` синхронно викликає `notFound()`, віддаючи пошуковому роботу суворий HTTP-статус `404` усередині локалізованого серверного компонента `app/[locale]/not-found.tsx`.
4. **Структуровані дані `JSON-LD` (`Schema.org`) та AI-маніфест `/llms.txt`:**
   - Хелпери `buildProfilePageJsonLd()` та `buildTechArticleJsonLd()` у `seo.ts` генерують серверний `<script type="application/ld+json">` (із екрануванням `<` ➔ `\u003c` проти XSS) на головній сторінці (`/`), резюме (`/cv`) та в усіх конспектах Бази Знань (`/knowledge-base/[...slug]`).
   - Статичний маршрут `apps/web/src/app/llms.txt/route.ts` (`force-static`) формує машиночитаний Markdown-паспорт портфоліо (профіль, комерційний трек-рекорд із метриками, 16 ADR та повний зміст Бази Знань) спеціально для LLM-агентів (**ChatGPT Search, Claude, Perplexity, Cursor**).

## 5. Архітектурний реєстр SEO-підсистеми

| Компонент SEO | Файл / Розташування | Призначення в продакшені |
| :--- | :--- | :--- |
| **SEO Core & JSON-LD Builders** | `apps/web/src/shared/lib/seo.ts` | Валідація `NEXT_PUBLIC_SITE_URL` (`parsed.origin`), генерація `canonical`, `hreflang`, `og:locale` та `JSON-LD` (`ProfilePage` / `TechArticle`) |
| **Adaptive Viewport & GoogleBot Rules** | `apps/web/src/app/[locale]/layout.tsx` | Системний `theme-color` (`#FAF8F5` / `#121211`), `authors`/`creator` та `max-image-preview: 'large'` |
| **Turborepo Env Invalidation** | `turbo.json` (`globalEnv`) | Автоматична перезбірка SSG-метаданих при зміні `NEXT_PUBLIC_SITE_URL` |
| **Robots.txt Generator** | `apps/web/src/app/robots.ts` | Статичні правила індексації (`allow: '/'`, `disallow: ['/api/', '/search-index/']`) |
| **Multilingual Sitemap.xml** | `apps/web/src/app/sitemap.ts` | Повна карта локалізованих маршрутів (`EN / UA / RU`) із `lastModified` з `.mdx` |
| **AI Discovery Manifest (`/llms.txt`)** | `apps/web/src/app/llms.txt/route.ts` | Структурований Markdown-маніфест досвіду, 16 ADR та каталогу статей для AI-пошуковиків |
| **OpenGraph Social Banner (`1200×630`)** | `apps/web/src/app/[locale]/opengraph-image.tsx` | Статична кодогенерація карток `Obsidian Editorial Dark` через `next/og` |
| **Browser & Apple Icons (`32×32`, `180×180`)** | `apps/web/src/app/icon.tsx`, `apple-icon.tsx` | Векторна генерація фавіконок `>_` через `ImageResponse` |
| **Strict HTTP 404 Catch-All** | `apps/web/src/app/[locale]/[...rest]/page.tsx` + `not-found.tsx` | Захист від Soft-404: повернення чесного HTTP `404` зі збереженням навігації `LocaleRootLayout` |
