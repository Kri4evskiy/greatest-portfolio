## 1. API `use()`: потокові проміси та умовний контекст

На відміну від `useContext`, виклик `use()` дозволений після ранніх `return` або всередині блоків `if`.

### Передача неблокуючого проміса з RSC на клієнт

```tsx title="Стрімінг проміса через use()"
'use client'
import { use } from 'react'

export function MetricsSummary({ metricsPromise }: { metricsPromise: Promise<MetricsDto> }) {
  const data = use(metricsPromise)
  return <span className="font-mono">{data.viewsCount} переглядів</span>
}
```

> [!TIP]
> Створюйте проміс у **Server Component** без `await`, огортайте клієнтський блок у `<Suspense>` та читайте результат через `use(promise)`, щоб не блокувати віддачу першого HTML-екрана.

## 2. Головні спрощення коду в React 19

| Задача | Як було в React 18 | Як стало в React 19 |
| :--- | :--- | :--- |
| Прокидання `ref` у DOM | `forwardRef<HTMLInputElement, Props>((props, ref) => ...)` | `function Input({ ref, ...props }: Props)` |
| Провайдер контексту | `<ThemeContext.Provider value={theme}>` | `<ThemeContext value={theme}>` |
| Стан відправки форми | Ручні `useState` для `isLoading` та `error` | `const [state, action, isPending] = useActionState(...)` |
| Мета-теги сторінки | Сторонні бібліотеки або ручні ефекти | Нативне підняття `<title>`, `<meta>`, `<link>` у `<head>` |
