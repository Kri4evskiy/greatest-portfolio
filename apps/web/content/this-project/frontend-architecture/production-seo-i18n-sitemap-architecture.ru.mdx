## 1. Трёхуровневая матрица локалей (`LOCALE_METADATA` как Single Source of Truth)

Главная особенность мультиязычного SEO в монорепозитории — то, что внутренний код языка, публичный URL-префикс, тег BCP 47 и стандарты поисковых роботов / мессенджеров подчиняются разным спецификациям.

Вместо дублирования словарей по фронтенду единый источник правды `LOCALE_METADATA` экспортируется из `packages/shared-schemas/src/locale.schema.ts` и используется в `apps/web/src/shared/lib/seo.ts`, `robots.ts` и `apps/web/src/shared/i18n/routing.ts` (`localePrefix: { mode: 'as-needed', prefixes: { uk: '/ua' } }`):

| Язык | Внутренний тип (`SupportedLocale` и суффикс `.mdx`) | Публичный URL-префикс (`urlPrefix`) | Поисковый стандарт ISO 639-1 (`<html lang>` и `hreflang`) | Стандарт мессенджеров (`ogLocale`) |
| :--- | :--- | :--- | :--- | :--- |
| **English (Default)** | `'en'` (`*.en.mdx`) | `''` (`/`, `/cv`, `/system-status`, `/knowledge-base`) | `en` (+ `x-default`) | `en_US` |
| **Українська** | `'uk'` (`*.uk.mdx`) | `'/ua'` (`/ua`, `/ua/cv`, `/ua/system-status`, `/ua/knowledge-base`) | `uk` | `uk_UA` |
| **Русский** | `'ru'` (`*.ru.mdx`) | `'/ru'` (`/ru`, `/ru/cv`, `/ru/system-status`, `/ru/knowledge-base`) | `ru` | `ru_RU` |

> [!IMPORTANT]
> По спецификации Google Search Central атрибут `hreflang` обязан использовать код языка по стандарту **ISO 639-1** (`uk` для украинского языка, а не код страны `ua`), но сам `href` должен указывать на реальный публичный URL (`https://domain.com/ua/...`). Поэтому `buildLanguageAlternatesMap()` связывает ключ `uk` напрямую с `LOCALE_METADATA.uk.urlPrefix` (`'/ua'`).

## 2. Единое SEO-ядро, валидация Origin и общий билдер `OpenGraph`

Валидация `NEXT_PUBLIC_SITE_URL` вынесена в `resolvePublicSiteUrl()` внутри `apps/web/src/shared/config/env.ts` (через Zod-схему `HttpOriginSchema` и `parseSafeHttpOrigin()`, с однократным предупреждением в продакшене вне `WORKFOLIO_DEMO_MODE=true`). Все хелперы в `apps/web/src/shared/lib/seo.ts` опираются на `LOCALE_METADATA` и `resolvePublicSiteUrl()`:

```typescript title="apps/web/src/shared/lib/seo.ts"
export function buildLocalizedPath(pathname: string, locale: SupportedLocale = DEFAULT_LOCALE): string {
  const normalizedPath = normalizeSeoPathname(pathname)
  const prefix = LOCALE_METADATA[locale].urlPrefix

  if (normalizedPath === '/') {
    return prefix || '/'
  }
  return `${prefix}${normalizedPath}`
}

export function buildOpenGraphMetadata(input: OpenGraphMetadataInput): NonNullable<Metadata['openGraph']> {
  const base = {
    title: input.title,
    description: input.description,
    url: buildLocalizedUrl(input.pathname, input.locale),
    siteName: SITE_NAME,
    locale: resolveOgLocale(input.locale),
    alternateLocale: resolveAlternateOgLocales(input.locale),
  }

  if (input.type === 'article') {
    return {
      ...base,
      type: 'article',
      ...(input.publishedTime ? { publishedTime: input.publishedTime } : {}),
      ...(input.tags && input.tags.length > 0 ? { tags: [...input.tags] } : {}),
    }
  }

  return { ...base, type: input.type ?? 'website' }
}
```

### Зачем нужен единый `buildOpenGraphMetadata()`
Next.js выполняет **поверхностное слияние (shallow merge)** объекта `openGraph` между `layout.tsx` и дочерними `page.tsx`. Без общего билдера переопределение `openGraph` на `/cv`, `/system-status` или `/knowledge-base/[...slug]` молча теряло бы `siteName` и `alternateLocale`. `buildOpenGraphMetadata()` гарантирует консистентные `siteName`, `locale` и `alternateLocale` на каждом маршруте (`[locale]/layout.tsx`, `[locale]/cv/page.tsx`, `[locale]/system-status/page.tsx`, `[locale]/knowledge-base/page.tsx`, `[locale]/knowledge-base/[...slug]/page.tsx`).

## 3. Гибридное SEO Базы Знаний (`sitemap.ts`, `robots.ts`) и гигиена Edge Proxy

Поскольку База Знаний разделена на публичный архитектурный blueprint (`/knowledge-base` + `/knowledge-base/this-project/**`) и защищённые Edge JWT конспекты, правила для поисковых роботов строго зеркалят `PUBLIC_KB_ROOT_SEGMENTS = ['this-project']`, обеспечивая **ноль `307`-редиректов для краулеров**:

1. **Гибридная фильтрация Sitemap (`apps/web/src/app/sitemap.ts`):**
   - Включает корневые хабы: `/` (`priority: 1.0`), `/cv` (`0.9`), `/knowledge-base` (`0.9`) и `/system-status` (`0.85`).
   - При обходе `getAllStaticKnowledgeSlugArrays()` пропускает защищённые ветки через `if (!isPublicKnowledgeBasePath(pathname)) continue`, добавляя в `sitemap.xml` только разделы и статьи `this-project/**` с реальными датами `publishedAt` для `EN / UA / RU` (`alternates.languages`).
2. **Динамический запрет защищённых категорий (`apps/web/src/app/robots.ts`):**
   - `buildProtectedKbDisallowRules()` берёт `KnowledgeCategoryEnum.options` за вычетом `PUBLIC_KB_ROOT_SEGMENTS` и генерирует правила запрета для всех 3 префиксов локалей (`''`, `'/ua'`, `'/ru'`), отдавая `disallow: ['/api/', '/search-index/', ...buildProtectedKbDisallowRules()]`.
3. **Явный matcher расширений статики (`apps/web/src/proxy.ts`):**
   - Мета-маршруты (`robots.ts`, `sitemap.ts`, `llms.txt/route.ts`, `icon.tsx`, `apple-icon.tsx`, `[locale]/opengraph-image.tsx`) обходят Edge Auth за счёт явного списка расширений (`ico|png|jpg|jpeg|gif|svg|webp|avif|pdf|css|js|mjs|map|woff|woff2|ttf|otf|txt|xml|json|webmanifest`) вместо широкого `.*\..*`.
4. **Защита от Soft-404 и `noindex`:**
   - Несуществующие маршруты внутри локали попадают в `app/[locale]/[...rest]/page.tsx` -> `notFound()` (честный HTTP `404` через `app/[locale]/not-found.tsx`).
   - В `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx` директива `export const dynamicParams = false` отсекает неизвестные слаги, а fallback-ветка `generateMetadata()` явно возвращает `robots: { index: false, follow: false }`.

## 4. XSS-безопасный `JSON-LD` (`ProfilePage`, `TechArticle`, `BreadcrumbList`), локализованные `OG`-карточки и `/llms.txt`

### Закалённая сериализация JSON-LD
Хелпер `serializeSafeJsonLd()` экранирует все 5 опасных символов для встраивания в `<script type="application/ld+json">` (`<`, `>`, `&`, `\u2028`, `\u2029`):

```typescript title="apps/web/src/shared/lib/seo.ts"
export function serializeSafeJsonLd(payload: Record<string, unknown>): string {
  return JSON.stringify(payload)
    .replace(/</g, '\\u003c')
    .replace(/>/g, '\\u003e')
    .replace(/&/g, '\\u0026')
    .replace(/\u2028/g, '\\u2028')
    .replace(/\u2029/g, '\\u2029')
}
```

- **Главная (`/`) и Резюме (`/cv`):** рендерят `ProfilePage` + `Person` (`buildProfilePageJsonLd()`).
- **Статьи Базы Знаний (`/knowledge-base/[...slug]`):** рендерят одновременно расширенный `TechArticle` (`mainEntityOfPage`, `publisher`, локализованный `image` на `/opengraph-image`, `datePublished`, `dateModified`, `keywords`) через `buildTechArticleJsonLd()` **и** навигационную цепочку `BreadcrumbList` через `buildBreadcrumbListJsonLd()`.

### Локализованные OpenGraph-карточки (`EN / UA / RU`) с `Inter` TTF и офлайн-фолбеком
`apps/web/src/app/[locale]/opengraph-image.tsx` (`1200×630`, `generateStaticParams` по `SUPPORTED_LOCALES`) генерирует локализованные баннеры `Obsidian Editorial Dark` (`OG_LOCALE_COPY` для `en`, `uk`, `ru`):
- Загружает кириллические TTF-начертания `Inter` (`400`, `700`) с Google Fonts через `fetchGoogleFontTtf()` (`AbortSignal.timeout(4000)`) с кэшированием промиса на уровне модуля (`cachedInterFontsPromise`).
- **Офлайн-фолбек:** если в изолированной сборке без сети не удалось получить TTF (`fonts.length === 0`), генератор автоматически переключается на `OG_LOCALE_COPY.en` и `sans-serif`, чтобы Satori никогда не рисовал «тофу»-квадраты (`□□□`).

### AI-манифест `/llms.txt`
`apps/web/src/app/llms.txt/route.ts` (`force-static`) формирует машиночитаемый Markdown-паспорт портфолио со ссылками на `/`, `/cv`, `/system-status`, `/knowledge-base/this-project`, коммерческим опытом, 16 ADR и структурой гибридной Базы Знаний (явно отмечая защищённые категории как закрытые Guest Pass и исключённые из индексации).

## 5. Архитектурный реестр SEO-подсистемы

| Компонент SEO | Файл / Расположение | Назначение в продакшене |
| :--- | :--- | :--- |
| **Матрица метаданных локалей** | `packages/shared-schemas/src/locale.schema.ts` | Единый контракт `LOCALE_METADATA` (`code`, `urlPrefix`, `intlLocale`, `ogLocale`) |
| **Валидация Origin из Env** | `apps/web/src/shared/config/env.ts` | `resolvePublicSiteUrl()` через Zod `HttpOriginSchema` + предупреждение в продакшене |
| **SEO-ядро и JSON-LD** | `apps/web/src/shared/lib/seo.ts` | `buildPageAlternates`, `buildOpenGraphMetadata` (`siteName` + `alternateLocale`), `serializeSafeJsonLd`, `ProfilePage`, расширенный `TechArticle`, `BreadcrumbList` |
| **Adaptive Viewport и GoogleBot** | `apps/web/src/app/[locale]/layout.tsx` | Системный `themeColor` (`#FAF8F5` / `#121211`), `authors`/`creator`, `max-image-preview: 'large'` |
| **Robots.txt Generator** | `apps/web/src/app/robots.ts` | Закрывает `/api/`, `/search-index/` и все защищённые категории БЗ во всех префиксах (`''`, `/ua`, `/ru`) |
| **Гибридный Sitemap.xml** | `apps/web/src/app/sitemap.ts` | Статические хабы (`/`, `/cv`, `/knowledge-base`, `/system-status`) + только публичная `this-project/**` (ноль `307`) |
| **AI-манифест (`/llms.txt`)** | `apps/web/src/app/llms.txt/route.ts` | Структурированный Markdown-паспорт опыта, 16 ADR и каталога БЗ для AI-поисковиков |
| **Локализованный OpenGraph (`1200×630`)** | `apps/web/src/app/[locale]/opengraph-image.tsx` | Локализованные карточки `EN / UA / RU` через `next/og`, `Inter` TTF (`400`/`700`) и офлайн-фолбек на EN |
| **Строгий HTTP 404 и Noindex** | `app/[locale]/[...rest]/page.tsx`, `not-found.tsx`, `knowledge-base/[...slug]/page.tsx` | Честный HTTP `404`, `dynamicParams = false` и `robots: { index: false, follow: false }` для 404-метаданных |
