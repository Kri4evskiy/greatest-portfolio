## 1. Migrating from pnpm 10 to pnpm 12 (Rust Core + SQLite Store)

In pnpm 12, legacy package.json build fields (onlyBuiltDependencies) were deprecated and removed in favor of a strict allowBuilds map inside pnpm-workspace.yaml. Any unlisted native package with postinstall scripts triggers ERR_PNPM_IGNORED_BUILDS.

```yaml
packages:
  - "apps/*"
  - "packages/*"

allowBuilds:
  "@biomejs/biome": true
  "@parcel/watcher": true
  "@prisma/client": true
  "@prisma/engines": true
  "@swc/core": true
  esbuild: true
  lefthook: true
  prisma: true
  sharp: true
```

## 2. Shared BuildKit Cache Mounts Across All 3 Services

Previously, web, api, and telemetry-ms downloaded 100+ MB of identical Linux binaries from scratch on every lockfile change. Mounting /root/.local/share/pnpm/store as a persistent BuildKit cache shares packages across all images:

```dockerfile
RUN corepack enable && corepack prepare pnpm@12.16.1 --activate && pnpm --version
RUN --mount=type=cache,id=pnpm,target=/root/.local/share/pnpm/store \
    pnpm install --frozen-lockfile --ignore-scripts
```

## 3. Stripping devDependencies While Preserving Generated Prisma Client

Running pnpm prune --prod --ignore-scripts after turbo run build removes Biome, Turbo, TypeScript, and Prisma CLI (~180 MB) from production runner containers while preserving the generated .prisma/client runtime artifact:

- Compressed telemetry-ms image: 64.3 MB
- Compressed api image: 78.2 MB (healthy PostgreSQL connection in 15ms)
- Compressed web standalone image: 85.6 MB
