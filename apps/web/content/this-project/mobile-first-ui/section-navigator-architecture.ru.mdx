## 1. Устранение замирания повторного клика по якорю в Next.js

Стандартный компонент `<Link href="/#projects">` в Next.js игнорирует прокрутку, если текущий `window.location.hash` в адресной строке уже совпадает с `#projects` после ручного скролла колесом мыши вверх.

### Прямой программный скролл и пассивный ScrollSpy

Наш хук `useSectionNavigation` перехватывает клик на главной странице и вызывает нативный `scrollIntoView` напрямую при каждом нажатии:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const element = document.getElementById(sectionId)
if (element) {
  element.scrollIntoView({ behavior: 'smooth', block: 'start' })
  window.history.replaceState(null, '', `#${sectionId}`)
}
```

> [!NOTE]
> Подсветка активной секции (`useActiveWorkfolioSection`) построена на `{ passive: true }` скролл-слушателе с троттлингом через `requestAnimationFrame`, что гарантирует плавные **60 FPS** без нагрузки на главный поток.

## 2. Адаптация компонентов по стандарту Mobile-First

Вынос навигации по секциям из `WorkfolioHeader` позволил перестроить каждый экран под реальные мобильные сценарии (переход из Telegram / LinkedIn со смартфона).

### Матрица адаптации ключевых узлов UI

| Узел интерфейса | Смартфоны и планшеты (`< md` / `< xl`) | Десктоп (`>= md` / `xl+`) |
| :--- | :--- | :--- |
| `WorkfolioHeader` | Лого + компактный дропдаун языка + `Base of Knowledge` + `ADR` | Сегментированный переключатель `EN / UA / RU` + статус-бейдж |
| `PageSectionNavigator` | Плавающая кнопка-таблетка под большой палец справа внизу | Парящая боковая панелька в стиле Notion справа от контента |
| `TechRadarTable` | Вертикальный стек карточек технологий с кнопкой `ADR` | Полноценная 6-колоночная таблица `TanStack Table` |
| `KnowledgeSidebar` | Закрытая по умолчанию шторка (авто-закрытие при выборе статьи) | Постоянное рекурсивное дерево разделов и подпунктов |
