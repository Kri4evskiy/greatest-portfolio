## 1. `/[locale]/knowledge-base/[...slug]` Catch-All Routing & Streaming Suspense

Articles live on disk at `apps/web/content/<topic>/<subtopic>/<slug>.<locale>.mdx`. Public URLs follow `next-intl`'s `as-needed` prefix policy (`en` default is **prefixless**, Ukrainian `uk` uses **`/ua`**, Russian `ru` uses **`/ru`**). A single catch-all route `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx` serves every depth without duplicating route files:

| `slug` Depth | Example Public URL (EN Default) | Rendered View in `page.tsx` |
| :--- | :--- | :--- |
| **1 segment (`[topic]`)** | `/knowledge-base/this-project` | **Topic Hub:** `TopicSubtopicTabs`, subfolder cards, and full section article list |
| **2 segments (`[topic, subtopic]`)** | `/knowledge-base/this-project/knowledge-engine` | **Subtopic Hub:** active subtopic tab and filtered article cards for that folder |
| **3 segments (`[...path, article]`)** | `/knowledge-base/this-project/knowledge-engine/server-mdx-ast-dual-theme-shiki` | **Article Page:** `TL;DR`, `<Suspense fallback={<ArticleBodySkeleton />}>`, `MdxArticleRenderer`, sticky `TOC`, and `Prev / Next` links |

At build time, `export const dynamicParams = false` locks routing strictly to pre-built slugs generated by `generateStaticParams()` (returning immediate `404` for unknown paths), while `<MdxArticleRenderer>` streams inside `<Suspense fallback={<ArticleBodySkeleton />}>` (from `apps/web/src/entities/knowledge-article/ui/knowledge-skeletons.tsx`):

```tsx title="apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx"
export const dynamicParams = false

export function generateStaticParams() {
  const slugArrays = getAllStaticKnowledgeSlugArrays()
  return SUPPORTED_LOCALES.flatMap((locale) =>
    slugArrays.map((slug) => ({
      locale,
      slug,
    })),
  )
}

// Inside KnowledgeCatchAllPage article branch:
<Suspense fallback={<ArticleBodySkeleton />}>
  <MdxArticleRenderer hast={article.hast} codeBlocks={article.codeBlocks} />
</Suspense>
```

### Primitive-Keyed `React.cache` Deduplication (`mdx-fs-loader.ts`)
Next.js calls `generateMetadata()` and `Page()` with distinct `slug: string[]` array references. Passing an array directly into `React.cache` causes a cache miss by reference identity. `apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts` joins segments into a primitive string key first (`segments.join('/')`) so both calls share the exact same memoized document per request on top of cross-request `mtimeMs` caching:

```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts"
const getArticleByRouteKey = cache((targetRoute: string, locale: SupportedLocale): MdxArticleDocument | null => {
  const entries = getAllCachedFrontmatterEntriesByLocale(locale)
  const matchedEntry = entries.find((e) => e.frontmatter.routePath === targetRoute)
  if (!matchedEntry) return null
  return loadCachedDocumentFromEntry(matchedEntry)
})

export function getArticleByPathSegments(segments: readonly string[], localeInput?: string): MdxArticleDocument | null {
  return getArticleByRouteKey(segments.join('/'), normalizeLocale(localeInput))
}
```

## 2. Hardened Zero-Eval HAST Pipeline & Link Sanitization

All `.mdx` parsing executes strictly on the server inside `apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts`:

1. **RCE-Hardened `gray-matter` (`parseFrontmatterOnly`):** explicitly disables `gray-matter`'s legacy `js` and `javascript` frontmatter eval engines as defense-in-depth:
   ```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts"
   const parsedMatter = matter(raw, {
     engines: {
       js: () => ({}),
       javascript: () => ({}),
     },
   })
   ```
2. **Zero-Eval `mdast` ➔ `HAST` (`unified`):** `remarkParse` + `remarkGfm` + `remarkDirective` decorates `h2–h4` headings, GitHub-style callouts (`> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`), task lists, and code blocks, converts registered `<Widget />` tags and `::sandbox` / `:::sandbox` directives into `div[data-mdx-widget]`, and strips arbitrary raw HTML blocks before `remarkRehype` produces `HastRoot` for `toJsxRuntime`.
3. **URL & Backslash Open-Redirect Guard (`apps/web/src/entities/knowledge-content/lib/link-sanitizer.ts`):** `classifySafeMarkdownLink()` and `isSafeMarkdownImageSrc()` reject `//` protocol-relative URLs **and** `/\` backslash-prefixed paths (`!trimmed.startsWith('//') && !trimmed.startsWith('/\\')`), allowlisting only `http:`, `https:`, and `mailto:` (links) or `http:` and `https:` (images).

## 3. Dual-Theme `Shiki v4` with FIFO Cache & `theme.css` (`0 KB` Client JS)

`MdxArticleRenderer` highlights all `codeBlocks` in parallel via `Promise.all` using `highlightCodeServer` (`apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts`):

```typescript title="apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts"
const SHIKI_THEMES = {
  light: 'github-light-default',
  dark: 'github-dark-default',
} as const

const MAX_SHIKI_CACHE_ENTRIES = 1000

async function renderHighlightedHtml(code: string, lang: string): Promise<string> {
  try {
    return await codeToHtml(code, { lang, themes: SHIKI_THEMES, defaultColor: false })
  } catch {
    try {
      return await codeToHtml(code, { lang: 'text', themes: SHIKI_THEMES, defaultColor: false })
    } catch {
      return `<pre class="shiki"><code>${escapeHtmlFallback(code)}</code></pre>`
    }
  }
}

export function highlightCodeServer(code: string, rawLanguage: string): Promise<string> {
  const normalized = rawLanguage.trim().toLowerCase()
  const lang = LANGUAGE_ALIASES[normalized] ?? (normalized || 'typescript')
  const cacheKey = `${lang}\0${code}`

  const existing = shikiCache.get(cacheKey)
  if (existing) return existing

  const promise = renderHighlightedHtml(code, lang).catch((error: unknown) => {
    shikiCache.delete(cacheKey)
    throw error
  })

  // FIFO eviction avoids cold-start cliff caused by wiping the entire cache at once
  if (shikiCache.size >= MAX_SHIKI_CACHE_ENTRIES) {
    const oldestKey = shikiCache.keys().next().value
    if (oldestKey !== undefined) {
      shikiCache.delete(oldestKey)
    }
  }
  shikiCache.set(cacheKey, promise)
  return promise
}
```

- **FIFO Eviction (`MAX_SHIKI_CACHE_ENTRIES = 1000`):** evicts only the oldest entry when full instead of clearing the whole `Map` (eliminating cold-start latency spikes).
- **Self-Healing `.catch()` Eviction:** removes rejected promises immediately so a transient grammar error never permanently poisons a snippet key.
- **Zero-JS CSS Cascade (`packages/ui/src/styles/theme.css`):** with `defaultColor: false`, Shiki emits `--shiki-light` and `--shiki-dark` custom properties resolved purely in CSS inside `@layer components`:

```css title="packages/ui/src/styles/theme.css"
@layer components {
  .shiki,
  .shiki span {
    color: var(--shiki-light);
    background-color: transparent;
    font-style: var(--shiki-light-font-style, inherit);
    font-weight: var(--shiki-light-font-weight, inherit);
  }

  .dark .shiki,
  .dark .shiki span {
    color: var(--shiki-dark);
    background-color: transparent;
    font-style: var(--shiki-dark-font-style, inherit);
    font-weight: var(--shiki-dark-font-weight, inherit);
  }
}
```

## 4. Lazy-Loaded Interactive MDX Widgets (`next/dynamic`) & Tree-Shaken `d3`

All four registered MDX widgets in `apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx` (`ReactRenderGraphD3`, `ArchitectureFlowD3`, `NestAiMcpDiagram`, `ArticleImageGrid`) are dynamically imported with `ssr: false` and explicit `<Skeleton />` heights (`min-h-[420px]` / `min-h-[320px]`) so standard text articles ship **0 KB** of diagram or D3 code:

```tsx title="apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx"
const ReactRenderGraphD3 = dynamic(() => import('./d3-react-render-graph').then((m) => m.ReactRenderGraphD3), {
  ssr: false,
  loading: () => <Skeleton className="my-6 min-h-[420px] w-full rounded-xl" />,
})
```

Inside the D3 sandboxes (`d3-react-render-graph.tsx`, `d3-architecture-flow.tsx`), we avoid namespace `import * as d3` in favor of **tree-shaken named imports** (`import { hierarchy, linkHorizontal, select, tree } from 'd3'` and `import { select } from 'd3'`), paired with `experimental.optimizePackageImports: ['lucide-react', 'd3', '@repo/ui', '@repo/shared-schemas']` in `apps/web/next.config.ts`.
