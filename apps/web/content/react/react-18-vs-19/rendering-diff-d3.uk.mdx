## 1. Ключова різниця між React 18 та React 19

| Критерій | React 18 (Ручна мемоїзація) | React 19 (Compiler + RSC) |
| :--- | :--- | :--- |
| Каскадні ререндери | Усе піддерево без ручного `React.memo` | Автоматичне відсікання незмінних гілок JSX |
| Стабільність посилань | Крихкі масиви залежностей `useCallback` | Автоматичні слоти кешу на етапі збірки |
| Асинхронні дані | Водоспади у `useEffect` або зовнішній клієнт | Потоковий `use(promise)` всередині `<Suspense>` |
| Передача `ref` | Обов’язкова обгортка `forwardRef` | Прямий проп `ref` у звичайній функції |

## 3. Інтеграція `D3.js` без конфліктів із Virtual DOM

Щоб імперативна математика `D3.js` не конфліктувала з React, проміжні координати ніколи не зберігаються у стані компонента:

```typescript title="Локальний режим віджета + ізоляція SVG"
const [mode, setMode] = useState<ReactRenderMode>('react19')
const svgRef = useRef<SVGSVGElement | null>(null)
```

- **Ізоляція DOM:** React володіє лише кореневим `<svg ref={svgRef} />`, а розрахунок `d3.tree()` та `d3.linkHorizontal()` виконується всередині `useEffect`.
- **Ліниве підвантаження (`next/dynamic`):** Модулі `D3.js` виключені зі стартового бандла візитки CV й завантажуються лише у статтях.
