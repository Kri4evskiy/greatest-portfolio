## Бюджет клиентского JavaScript в Next.js App Router

Даже при использовании `React Server Components` базовый клиентский рантайм (`react-dom/client` + гидратация + планировщик) занимает существенную долю в `First Load JS`.

## Три уровня оптимизации бандла в проекте

1. **Vercel `bundle-dynamic-imports` & `optimizePackageImports`:** Тяжелые интерактивные модули (`D3.js` симуляции, модальные инспекторы) загружаются через `next/dynamic`, а иконки `lucide-react` и `@repo/ui` проходят точечный tree-shaking.
2. **Минимизация сериализации RSC (`server-serialization`):** Через границу `Server Component -> Client Component` передаются только компактные структуры данных.
3. **Экспериментальный флаг `ENABLE_REDACT` в `next.config.ts`:** Подготовлена архитектурная точка подключения синхронного клиентского рантайма `TanStack Redact` и анализатора бандла для сокращения рантайм-оверхеда на ~20% (~35 KB gzip).
