## 1. Усунення завмирання повторного кліку по якорю в Next.js

Стандартний компонент `<Link href="/#projects">` у Next.js пропускає прокрутку, якщо поточний `window.location.hash` вже дорівнює `#projects` після ручного скролу вгору.

### Прямий програмний скрол та пасивний ScrollSpy

Хук `useSectionNavigation` перехоплює клік на головній сторінці й гарантовано викликає плавну прокрутку при кожному натисканні:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const element = document.getElementById(sectionId)
if (element) {
  element.scrollIntoView({ behavior: 'smooth', block: 'start' })
  window.history.replaceState(null, '', `#${sectionId}`)
}
```

> [!NOTE]
> Відстеження активної секції (`useActiveWorkfolioSection`) працює на `{ passive: true }` слухачі подій з тротлінгом через `requestAnimationFrame`, зберігаючи стабільні **60 FPS**.

## 2. Адаптивні патерни інтерфейсу за брейкпоінтами

Винесення навігації по секціях із шапки дозволило спроєктувати кожен вузол за принципом **Mobile-First**.

### Матриця адаптації компонентів

| Вузол інтерфейсу | Смартфони та планшети (`< md` / `< xl`) | Десктоп (`>= md` / `xl+`) |
| :--- | :--- | :--- |
| `WorkfolioHeader` | Лого + компактний дропдаун мови + `Base of Knowledge` + `ADR` | Повний перемикач `EN / UA / RU` + статус-бейдж |
| `PageSectionNavigator` | Плаваюча кнопка-пігулка в правому нижньому кутку | Паряща бічна панель у стилі Notion праворуч |
| `TechRadarTable` | Стек компактних карток технологій з кнопкою `ADR` | Інтерактивна 6-колонкова таблиця `TanStack Table` |
| `KnowledgeSidebar` | Згорнута за замовчуванням шторка (закривається при виборі) | Постійне рекурсивне дерево розділів та підпунктів |
