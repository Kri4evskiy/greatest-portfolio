## 1. Миттєвий відгук через `useOptimistic`

```tsx title="Оптимістичний лічильник реакцій"
'use client'
import { useOptimistic } from 'react'

export function HelpfulButton({ count, onVote }: { count: number; onVote: () => Promise<void> }) {
  const [optimisticCount, addOptimistic] = useOptimistic(count, (curr, delta: number) => curr + delta)

  return (
    <form
      action={async () => {
        addOptimistic(1)
        await onVote()
      }}
    >
      <button type="submit">Корисно ({optimisticCount})</button>
    </form>
  )
}
```

## 2. Коли брати нативні Actions, а коли `React Hook Form`

| Задача | React 19 `<form action>` | `React Hook Form` + `Zod` + `TanStack Query` |
| :--- | :--- | :--- |
| Проста серверна дія на 1–2 поля | **Ідеально** (`0 KB` зайвого JS) | Надлишково |
| Складна клієнтська схема `Zod` на льоту | Потребує ручного розбору помилок | **Ідеально** (`zodResolver` без ререндерів форми) |
| Синхронізація з `IndexedDB` кешем | Відсутня з коробки | **Ідеально** (`queryClient` + персистер) |
