## 1. Детерминированный `#hash`-скролл в Next.js App Router

Стандартный роутер Next.js (`<Link href="/#projects">`) пропускает прокрутку, если в адресной строке уже стоит `#projects`, а пользователь прокрутил страницу вверх колесом мыши и кликнул по ссылке повторно.

Чтобы навигация по секциям работала безотказно, хук `useSectionNavigation` разделяет межстраничный переход (`router.push`) и внутристраничный программный скролл:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const scrollToSection = useCallback(
  (sectionId: WorkfolioSectionId) => {
    if (pathname !== '/') {
      router.push(`/#${sectionId}`)
      return
    }

    const element = document.getElementById(sectionId)
    if (element) {
      element.scrollIntoView({ behavior: 'smooth', block: 'start' })
      window.history.replaceState(null, '', `#${sectionId}`)
    }
  },
  [pathname, router],
)
```

Каждая целевая секция главной страницы размечена классом `scroll-mt-20`, чтобы фиксированная верхняя шапка (`h-14`) никогда не перекрывала заголовок блока после остановки скролла.

## 2. Пассивный `ScrollSpy` на `requestAnimationFrame` (`60 FPS`)

Для отслеживания текущей читаемой секции на длинных страницах используется пассивный слушатель прокрутки, синхронизированный с частотой обновления экрана через `requestAnimationFrame`:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
useEffect(() => {
  let rafId: number | null = null

  const updateActiveSection = () => {
    rafId = null
    const triggerLine = window.innerHeight * 0.28
    let currentSection: WorkfolioSectionId = WORKFOLIO_SECTION_IDS[0]

    for (const id of WORKFOLIO_SECTION_IDS) {
      const el = document.getElementById(id)
      if (!el) continue
      if (el.getBoundingClientRect().top <= triggerLine) {
        currentSection = id
      }
    }
    setActiveSection((prev) => (prev === currentSection ? prev : currentSection))
  }

  const onScroll = () => {
    if (rafId === null) {
      rafId = window.requestAnimationFrame(updateActiveSection)
    }
  }

  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

## 3. Эргономика `PageSectionNavigator` (`< xl` против `xl+`)

Вместо перегрузки верхней шапки `WorkfolioHeader` списком якорных ссылок навигация по секциям вынесена в отдельный адаптивный узел `PageSectionNavigator`:

| Брейкпоинт | Форм-фактор | Инженерная деталь |
| :--- | :--- | :--- |
| **Десктоп (`xl+`)** | Парящий вертикальный индикатор справа (`right-5 top-1/2`) | Показывает прогресс чтения и разворачивает подписи секций при наведении |
| **Мобильные и планшеты (`< xl`)** | Плавающая кнопка-таблетка в правом нижнем углу (`bottom-4 right-4`) | Находится в естественной зоне большого пальца; у `WorkfolioFooter` задан `pb-20 xl:pb-10`, чтобы кнопка не перекрывала копирайт и статус SSE |
