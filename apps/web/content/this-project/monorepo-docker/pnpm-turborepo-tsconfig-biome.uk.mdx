## 1. Структура воркспейсу `pnpm 12.21.0`, захист `allowBuilds` та `sideEffects`

Кореневий `package.json` фіксує `"packageManager": "pnpm@12.21.0"` і `"engines": { "node": ">=22.0.0" }`, а всі налаштування воркспейсу й безпеки ланцюга постачання живуть **суворо в `pnpm-workspace.yaml`** — ніколи в застарілій секції `"pnpm"` (на кшталт `onlyBuiltDependencies`) всередині `package.json`. У **pnpm 12** будь-які сторонні `postinstall`-скрипти заблоковані за замовчуванням; компілювати нативні бінарники дозволено лише пакетам із `allowBuilds`:

```yaml title="pnpm-workspace.yaml"
packages:
  - "apps/*"
  - "packages/*"

allowBuilds:
  "@biomejs/biome": true
  "@parcel/watcher": true
  "@prisma/engines": true
  "@swc/core": true
  esbuild: true
  lefthook: true
  prisma: true
  sharp: true
```

| Шар монорепозиторію | Пакет | Tree-shaking (`sideEffects`) | Призначення |
| :--- | :--- | :---: | :--- |
| **Застосунки (`apps/*`)** | `@repo/web`, `@repo/api`, `@repo/telemetry-ms` | — | Next.js 16 фронтенд, NestJS 12 REST API та мікросервіс живої SSE-телеметрії |
| **Контракти (`packages/shared-schemas`)** | `@repo/shared-schemas` | `false` | Чисті ESM Zod-схеми, DTO, константи кук/локалей і RBAC-хелпери, скомпільовані в `./dist/index.js` |
| **Дизайн-система (`packages/ui`)** | `@repo/ui` | `["*.css"]` | Матриця токенів `theme.css` / `globals.css`, Tailwind v4 `@theme inline`, примітиви `Radix UI` та `Storybook` |

> [!TIP]
> **Чому `sideEffects` різниться у внутрішніх пакетів:** `packages/shared-schemas/package.json` декларує `"sideEffects": false`, дозволяючи бандлерам агресивно вирізати невикористані Zod-схеми й хелпери. `packages/ui/package.json` декларує `"sideEffects": ["*.css"]`, щоб імпорти `@repo/ui/globals.css` і `@repo/ui/theme.css` зберігалися під час збірки, тоді як невикористані React-компоненти й примітиви Radix залишалися повністю tree-shakeable.

## 2. Граф задач і кешування в `Turborepo`

Конфігурація `turbo.json` оркеструє всі 8 задач воркспейсу зі стрімінговим виводом (`"ui": "stream"`), явною інвалідацією кешу за `globalDependencies` і `globalEnv`, топологічною збіркою `"dependsOn": ["^build"]` та паралельною перевіркою типів `"dependsOn": ["^typecheck"]`:

```json title="turbo.json"
{
  "$schema": "https://turbo.build/schema.json",
  "ui": "stream",
  "globalDependencies": ["tsconfig.base.json", "pnpm-workspace.yaml"],
  "globalEnv": ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"],
  "globalPassThroughEnv": ["FORCE_PNPM"],
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**", "src/generated/**", "storybook-static/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "build-storybook": {
      "dependsOn": ["^build"],
      "outputs": ["storybook-static/**"]
    },
    "typecheck": {
      "dependsOn": ["^typecheck"]
    },
    "lint": {
      "dependsOn": ["^lint"]
    },
    "test": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:coverage": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": ["coverage/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:e2e": {
      "dependsOn": ["build"],
      "cache": false,
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE", "CI", "WORKFOLIO_DEMO_MODE"]
    },
    "dev": {
      "dependsOn": ["^build"],
      "cache": false,
      "persistent": true
    }
  }
}
```

- **`globalEnv: ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"]`** гарантує інвалідацію кешу Next.js при зміні внутрішньої адреси API або канонічного домену (SEO canonicals, Open Graph, proxy rewrites).
- **`test` і `test:coverage`** залежать від `^build`, щоб `@repo/shared-schemas` був зібраний до запуску Vitest, а **`test:e2e`** залежить від `build` поточного пакета, вимикає кешування (`cache: false`) і прокидає `CI` та `WORKFOLIO_DEMO_MODE`.

## 3. Каскад суворої типізації `tsconfig.base.json`

Щоб виключити клас помилок `Cannot read properties of undefined` у рантаймі, всі пакети монорепозиторію наслідують кореневий профіль `tsconfig.base.json`:

```json title="tsconfig.base.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "resolveJsonModule": true,
    "allowJs": false,
    "isolatedModules": true,
    "moduleDetection": "force",
    "noEmit": true,
    "skipLibCheck": true,
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "noFallthroughCasesInSwitch": true,
    "noImplicitReturns": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  }
}
```

> [!IMPORTANT]
> Опція `noUncheckedIndexedAccess: true` автоматично додає `| undefined` до будь-якого звернення за індексом масиву чи словника (`items[0]`, `record[key]`), змушуючи явно перевіряти граничні випадки на етапі компіляції.

## 4. Єдиний лінтер, захист від циклів імпортів і форматер `Biome 2.6.4`

Замість десятка конфліктуючих плагінів `ESLint + Prettier` увесь код і стилі Tailwind v4 перевіряються за `~100 мс` одним Rust-бінарником (`@biomejs/biome` `2.6.4`) із конфігом `biome.json`:

```json title="biome.json"
{
  "$schema": "https://biomejs.dev/schemas/2.6.4/schema.json",
  "vcs": {
    "enabled": true,
    "clientKind": "git",
    "useIgnoreFile": true
  },
  "assist": {
    "actions": {
      "source": { "organizeImports": "on" }
    }
  },
  "linter": {
    "enabled": true,
    "rules": {
      "preset": "recommended",
      "correctness": {
        "noUnusedVariables": "error",
        "noUnusedImports": "error",
        "useExhaustiveDependencies": "warn"
      },
      "suspicious": {
        "noExplicitAny": "error",
        "noImportCycles": "error",
        "noArrayIndexKey": "warn",
        "noUnknownAtRules": "off"
      },
      "style": {
        "noNonNullAssertion": "error",
        "useConst": "error",
        "useImportType": "off"
      }
    }
  },
  "javascript": {
    "parser": { "unsafeParameterDecoratorsEnabled": true }
  },
  "css": {
    "parser": { "tailwindDirectives": true }
  }
}
```

Ключові архітектурні запобіжники в `biome.json`:
- **`suspicious.noImportCycles: "error"`:** примусово підтримує ациклічний граф модулів на етапі лінтингу як у FSD-Modular шарах фронтенду, так і в модулях NestJS — виявляючи циклічні імпорти ще до появи `undefined` DI-токенів чи помилок ініціалізації бандлера.
- **`javascript.parser.unsafeParameterDecoratorsEnabled: true` і `style.useImportType: "off"`:** зберігають сумісність із декораторами параметрів конструктора NestJS (`@Inject()`, `@Body()`) та рантайм-метаданими `emitDecoratorMetadata`.
- **`css.parser.tailwindDirectives: true` і `noUnknownAtRules: "off"`:** нативно розбирають директиви Tailwind v4 (`@theme inline`, `@custom-variant`) без вимкнення форматування CSS.
