## 1. Deterministic `#hash` Scrolling in Next.js App Router

Standard Next.js `<Link href="/#projects">` navigation skips scrolling if `window.location.hash` already equals `#projects` after the user manually scrolls back up and clicks the link again.

To make section jumps deterministic, `useSectionNavigation` separates cross-route transitions (`router.push`) from in-page programmatic scrolling:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
const scrollToSection = useCallback(
  (sectionId: WorkfolioSectionId) => {
    if (pathname !== '/') {
      router.push(`/#${sectionId}`)
      return
    }

    const element = document.getElementById(sectionId)
    if (element) {
      element.scrollIntoView({ behavior: 'smooth', block: 'start' })
      window.history.replaceState(null, '', `#${sectionId}`)
    }
  },
  [pathname, router],
)
```

Every target `<section id="...">` includes `scroll-mt-20` so the sticky top header (`h-14`) never obscures section headings after the smooth scroll finishes.

## 2. Passive `requestAnimationFrame` ScrollSpy (`60 FPS`)

To highlight the currently visible section without blocking the main thread, `useActiveWorkfolioSection` combines a `{ passive: true }` scroll listener with `requestAnimationFrame` throttling:

```typescript title="apps/web/src/hooks/use-section-navigation.ts"
useEffect(() => {
  let rafId: number | null = null

  const updateActiveSection = () => {
    rafId = null
    const triggerLine = window.innerHeight * 0.28
    let currentSection: WorkfolioSectionId = WORKFOLIO_SECTION_IDS[0]

    for (const id of WORKFOLIO_SECTION_IDS) {
      const el = document.getElementById(id)
      if (!el) continue
      if (el.getBoundingClientRect().top <= triggerLine) {
        currentSection = id
      }
    }
    setActiveSection((prev) => (prev === currentSection ? prev : currentSection))
  }

  const onScroll = () => {
    if (rafId === null) {
      rafId = window.requestAnimationFrame(updateActiveSection)
    }
  }

  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

## 3. `PageSectionNavigator` Ergonomics (`< xl` vs `xl+`)

Rather than crowding `WorkfolioHeader` with in-page links, section navigation lives in a dedicated responsive component:

| Breakpoint | Form Factor | Engineering Detail |
| :--- | :--- | :--- |
| **Desktop (`xl+`)** | Floating vertical rail on the right (`right-5 top-1/2`) | Displays reading progress and expands section labels on hover |
| **Mobile & Tablet (`< xl`)** | Floating pill in the bottom-right thumb zone (`bottom-4 right-4`) | `WorkfolioFooter` adds `pb-20 xl:pb-10` so the floating trigger never overlaps copyright or live SSE status |
