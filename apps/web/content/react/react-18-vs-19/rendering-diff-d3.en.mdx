## 1. Side-by-Side Comparison: React 18 vs React 19

| Dimension | React 18 (Manual Memoization) | React 19 (Compiler + RSC) |
| :--- | :--- | :--- |
| Subtree Re-renders | Cascades down unless wrapped in `React.memo` | Skips unchanged JSX subtrees automatically |
| Reference Stability | Fragile (`useMemo` / `useCallback` arrays) | Compiler-managed memo cache slots |
| Async Data in Client | `useEffect` fetch waterfalls or external store | `use(promise)` with `<Suspense>` streaming |
| Imperative DOM (`ref`) | `forwardRef` wrapper required | Direct `ref` prop on function components |

## 3. Integrating `D3.js` + `Zustand` Without Extra Re-renders

Interactive SVG graphs built with `D3.js` clash with React's Virtual DOM if animation coordinates live in `useState`. Our architecture enforces two rules:

```typescript title="Atomic Zustand Subscription + Imperative SVG Ref"
const mode = useUIStore((s) => s.reactGraphMode)
const svgRef = useRef<SVGSVGElement | null>(null)
```

- **DOM Isolation:** React renders only the empty `<svg ref={svgRef} />` shell; `d3.tree()` and `d3.linkHorizontal()` mutate nodes imperatively inside `useEffect`.
- **On-Demand Chunking (`next/dynamic`):** `D3.js` is excluded from the CV home bundle and loaded lazily only inside Knowledge Base articles.
