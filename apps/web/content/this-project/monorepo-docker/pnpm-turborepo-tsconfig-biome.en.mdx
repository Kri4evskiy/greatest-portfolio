## 1. `pnpm 12.21.0` Workspace Layout, `allowBuilds` & Package `sideEffects`

Root `package.json` pins `"packageManager": "pnpm@12.21.0"` and `"engines": { "node": ">=22.0.0" }`, while all workspace topology and supply-chain settings live **strictly in `pnpm-workspace.yaml`**—never inside a legacy `"pnpm"` section (such as `onlyBuiltDependencies`) in `package.json`. In **pnpm 12**, third-party `postinstall` scripts are blocked by default; only explicitly listed native packages under `allowBuilds` may run build scripts:

```yaml title="pnpm-workspace.yaml"
packages:
  - "apps/*"
  - "packages/*"

allowBuilds:
  "@biomejs/biome": true
  "@parcel/watcher": true
  "@prisma/engines": true
  "@swc/core": true
  esbuild: true
  lefthook: true
  prisma: true
  sharp: true
```

| Monorepo Layer | Package | Tree-Shaking (`sideEffects`) | Responsibility |
| :--- | :--- | :---: | :--- |
| **Applications (`apps/*`)** | `@repo/web`, `@repo/api`, `@repo/telemetry-ms` | — | Next.js 16 frontend, NestJS 12 REST API, and live SSE telemetry microservice |
| **Contracts (`packages/shared-schemas`)** | `@repo/shared-schemas` | `false` | Pure ESM Zod schemas, DTOs, cookie/locale constants, and RBAC helpers compiled to `./dist/index.js` |
| **Design System (`packages/ui`)** | `@repo/ui` | `["*.css"]` | `theme.css` / `globals.css` token matrix, Tailwind v4 `@theme inline`, `Radix UI` primitives, and `Storybook` |

> [!TIP]
> **Why `sideEffects` differs across internal packages:** `packages/shared-schemas/package.json` declares `"sideEffects": false` so bundlers can drop unused Zod schemas and helpers aggressively. `packages/ui/package.json` declares `"sideEffects": ["*.css"]` so importing `@repo/ui/globals.css` or `@repo/ui/theme.css` is never pruned while unused React components and Radix primitives remain fully tree-shakeable.

## 2. `Turborepo` Task Graph & Artifact Caching

`turbo.json` orchestrates all 8 workspace tasks with streaming output (`"ui": "stream"`), explicit cache invalidation on `globalDependencies` and `globalEnv`, topological `"dependsOn": ["^build"]` for build/test/dev pipelines, and parallel `"dependsOn": ["^typecheck"]` for type checking:

```json title="turbo.json"
{
  "$schema": "https://turbo.build/schema.json",
  "ui": "stream",
  "globalDependencies": ["tsconfig.base.json", "pnpm-workspace.yaml"],
  "globalEnv": ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"],
  "globalPassThroughEnv": ["FORCE_PNPM"],
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**", "src/generated/**", "storybook-static/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "build-storybook": {
      "dependsOn": ["^build"],
      "outputs": ["storybook-static/**"]
    },
    "typecheck": {
      "dependsOn": ["^typecheck"]
    },
    "lint": {
      "dependsOn": ["^lint"]
    },
    "test": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:coverage": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": ["coverage/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:e2e": {
      "dependsOn": ["build"],
      "cache": false,
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE", "CI", "WORKFOLIO_DEMO_MODE"]
    },
    "dev": {
      "dependsOn": ["^build"],
      "cache": false,
      "persistent": true
    }
  }
}
```

- **`globalEnv: ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"]`** ensures changing the internal API origin or canonical public URL busts cached Next.js builds (SEO canonicals, Open Graph, proxy rewrites).
- **`test` & `test:coverage`** depend on `^build` so `@repo/shared-schemas` is compiled before Vitest runs, while **`test:e2e`** depends on same-package `build` and disables caching (`cache: false`) with `CI` and `WORKFOLIO_DEMO_MODE` passed through.

## 3. Strict TypeScript Cascade (`tsconfig.base.json`)

To eliminate runtime `Cannot read properties of undefined` bugs, every workspace package extends the root `tsconfig.base.json` profile:

```json title="tsconfig.base.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "resolveJsonModule": true,
    "allowJs": false,
    "isolatedModules": true,
    "moduleDetection": "force",
    "noEmit": true,
    "skipLibCheck": true,
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "noFallthroughCasesInSwitch": true,
    "noImplicitReturns": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  }
}
```

> [!IMPORTANT]
> `noUncheckedIndexedAccess: true` automatically appends `| undefined` to every array or dictionary index lookup (`items[0]`, `record[key]`), forcing explicit boundary checks at compile time.

## 4. Unified Linting, Import-Cycle Guard & Formatting with `Biome 2.6.4`

Instead of maintaining a fragile chain of `ESLint + Prettier` plugins, the entire codebase and Tailwind v4 CSS stylesheets are formatted and linted in `~100 ms` via a single Rust binary (`@biomejs/biome` `2.6.4`) configured in `biome.json`:

```json title="biome.json"
{
  "$schema": "https://biomejs.dev/schemas/2.6.4/schema.json",
  "vcs": {
    "enabled": true,
    "clientKind": "git",
    "useIgnoreFile": true
  },
  "assist": {
    "actions": {
      "source": { "organizeImports": "on" }
    }
  },
  "linter": {
    "enabled": true,
    "rules": {
      "preset": "recommended",
      "correctness": {
        "noUnusedVariables": "error",
        "noUnusedImports": "error",
        "useExhaustiveDependencies": "warn"
      },
      "suspicious": {
        "noExplicitAny": "error",
        "noImportCycles": "error",
        "noArrayIndexKey": "warn",
        "noUnknownAtRules": "off"
      },
      "style": {
        "noNonNullAssertion": "error",
        "useConst": "error",
        "useImportType": "off"
      }
    }
  },
  "javascript": {
    "parser": { "unsafeParameterDecoratorsEnabled": true }
  },
  "css": {
    "parser": { "tailwindDirectives": true }
  }
}
```

Key architectural safeguards in `biome.json`:
- **`suspicious.noImportCycles: "error"`:** enforces an acyclic module dependency graph at lint time across both frontend FSD-Modular layers and NestJS backend modules, catching circular imports before they cause `undefined` DI tokens or bundler initialization glitches.
- **`javascript.parser.unsafeParameterDecoratorsEnabled: true` & `style.useImportType: "off"`:** preserves NestJS constructor parameter decorators (`@Inject()`, `@Body()`) and runtime metadata reflection required by `emitDecoratorMetadata`.
- **`css.parser.tailwindDirectives: true` & `noUnknownAtRules: "off"`:** natively parses Tailwind v4 `@theme inline` and `@custom-variant` rules without disabling CSS formatting.
