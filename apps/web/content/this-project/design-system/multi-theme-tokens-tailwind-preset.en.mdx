## 1. Two-Dimensional Semantic Token Matrix (`Mode` × `Palette`)

Instead of coupling components to raw Tailwind palette classes (`slate-*`, `emerald-*`, `amber-*`), the entire color system is defined as semantic HSL CSS variables (supporting alpha modifiers via native `color-mix()` in Tailwind v4 as well as SVG attributes like `hsl(var(--chart-1))`):

- **Surface Hierarchy:** `--background`, `--surface-subtle`, `--surface-elevated`, `--card`, `--popover`.
- **Semantic Statuses:** `--success`, `--warning`, `--info`, `--destructive` (paired with `*-foreground`).
- **Visualization & Code:** `--chart-1..4` for SVG/D3 diagrams and `--code-bg`, `--code-header`, `--code-border` for code blocks.

```css title="packages/ui/src/styles/theme.css"
@custom-variant dark (&:where(.dark, .dark *));

:root {
  --background: 40 20% 99%;
  --surface-subtle: 40 16% 96.5%;
  --surface-elevated: 0 0% 100%;
  --primary: 24 10% 12%;
  --success: 158 64% 32%;
  --warning: 32 92% 38%;
  --info: 214 84% 44%;
}

:root.dark,
.dark {
  --background: 24 10% 8%;
  --surface-subtle: 24 9% 10%;
  --surface-elevated: 24 9% 13%;
  --primary: 40 15% 95%;
  --success: 156 68% 54%;
}

@theme inline {
  --color-background: hsl(var(--background));
  --color-surface-subtle: hsl(var(--surface-subtle));
  --color-primary: hsl(var(--primary));
  --color-success: hsl(var(--success));
  --radius-sm: calc(var(--radius) - 4px);
  --radius-md: calc(var(--radius) - 2px);
  --radius-lg: var(--radius);
}
```

### Live 2D Appearance Switcher & Zero-FOUC Hydration

In the header, [`ThemeToggle`](apps/web/src/widgets/header/theme-toggle.tsx) is composed from `@repo/ui` primitives (`Button`, `Tooltip` + `Popover`) and acts as a pure UI control over both orthogonal axes:
- **Theme (`Light / Dark / System`):** managed by `next-themes` via `.dark`.
- **Palette Preset:** `Warm Paper` (`default`), `Graphite`, or `Sepia` (stored in `localStorage['workfolio-palette']` and synced to `html[data-palette]` via `@/shared/store/use-ui-store`).

To prevent Flash of Unstyled Content (FOUC) when reloading with `Graphite` or `Sepia` active, `LocaleRootLayout` injects an allowlisted static `PALETTE_INIT_SCRIPT` directly in `<head>` before hydration, while `ThemeProvider` handles post-mount palette hydration and cross-tab `storage` synchronization imperatively via `uiStore.getState().actions.syncPaletteFromStorage()` (zero extra `useSyncExternalStore` subscriptions or root re-renders).

> [!TIP]
> Separating `.dark` from `data-palette` and wrapping runtime tokens in `@theme inline` makes adding a new theme or `multi-tenant / white-label` brand a pure CSS variable override with zero changes to React components.

## 2. CSS-First Architecture, Cascade Layers & Baseline UX

To keep `@repo/ui` self-contained and agnostic of `apps/web`, the UI package exports a pure token-and-layer stylesheet `@repo/ui/theme.css` (without `@import "tailwindcss";`), while Storybook compiles `packages/ui/src/styles/globals.css` with `@tailwindcss/vite`.

In `apps/web`, [`globals.css`](apps/web/src/app/globals.css) acts as the **Composition Root** compiled by `@tailwindcss/postcss`:

```css title="apps/web/src/app/globals.css"
@import "tailwindcss";
@import "@repo/ui/theme.css";

@source "../";
@source "../../content";
@source "../../../../packages/ui/src";
```

Inside `theme.css`, rules are organized intentionally across **CSS Cascade Layers**:
1. **`@layer base`:** Sets default `border-color: hsl(var(--border))`, active button `cursor: pointer`, `scrollbar-gutter: stable` (eliminates 15px layout shift when modals lock scrolling on Windows), `scrollbar-width: thin`, `scroll-padding-top: 5rem`, smooth scroll when motion is allowed (paired with `data-scroll-behavior="smooth"` on `<html>` in `LocaleRootLayout`), and `text-wrap: balance` / `text-wrap: pretty`.
2. **`@layer components`:** Isolates `.shiki` dual-theme syntax rules, GPU-composited `@starting-style` entry animations (`opacity` + `scale`) for `[data-dialog-overlay]` / `[data-dialog-content]`, and pure CSS `@keyframes` (`ui-popper-in` / `ui-popper-out` using `data-state`, `data-side`, and `--radix-popper-transform-origin`) for `[data-popover-content]` and `[data-tooltip-content]` — synchronized with Radix Popper `isPositioned` (`animation: none` while measuring off-screen) and `<Presence>` exit timing.
3. **Unlayered override:** `@media (prefers-reduced-motion: reduce)` sits intentionally *outside* `@layer` so it supersedes Tailwind's `@layer utilities` (`transition-*`, `animate-*`) without needing `!important`.

Both `apps/web/package.json` and `packages/ui/package.json` pin `"browserslist": ["Chrome >= 111", "Edge >= 111", "Firefox >= 128", "Safari >= 16.4"]` so `Lightning CSS` and `Next.js SWC` emit zero legacy polyfills for `@property` and `color-mix()`.

## 3. Zero-CLS Typography, `@container` Queries & Conscious Trade-offs

- **Self-Hosted Zero-CLS Web Fonts:** `LocaleRootLayout` loads `Inter` and `JetBrains_Mono` (`latin` + `cyrillic` subsets, `display: 'swap'`) via `next/font/google`, exporting `--font-inter` and `--font-jetbrains-mono` mapped to `--font-sans` and `--font-mono` in `@theme inline`. Next.js downloads and bundles `.woff2` assets statically under `'self'` at build time (`0` external requests at runtime, `0` CLS), allowing CSP `font-src` to stay locked down to `'self' data:`.
- **Targeted Container Queries (`@container`):** `@repo/ui` `Card` declares `@container` so Knowledge Base article cards (`@xs:flex-row`, `@sm:text-lg`) and MDX `<ArticleImageGrid />` (`@md:grid-cols-2`) adapt to the width of their actual column—whether displayed full-width or squeezed between the sidebar and TOC.
- **Conscious Modern Web Platform Trade-offs:**
  - **Radix Dialog + `@starting-style` vs raw `<dialog>`:** Keeping `@radix-ui/react-dialog` (and migrating `CommandPaletteModal` onto it) guarantees battle-tested focus trapping, `aria-modal`, and cross-browser scroll-locking, while layering modern CSS `@starting-style` transitions cleanly on top.
  - **Deferring `oklch()`, CSS Anchor Positioning & `light-dark()`:** Native anchor positioning and `light-dark()` still trail our `browserslist` baseline (`Safari 16.4+`, `Firefox 128+`), while channel-based HSL (`H S% L%`) keeps tokens human-readable, natively compatible with `hsl(var(--chart-*))` in D3 SVG nodes, and works with Tailwind v4 `color-mix()` opacity modifiers.

## 4. Responsive Data Views & 100% Storybook Coverage

For information-dense components, rather than squeezing wide tables onto `360px` screens, the UI switches representation patterns by breakpoint, while every primitive in `packages/ui/src/components/*` (such as `Button`, `Dialog`, `Popover`, `Tabs`, `ToggleGroup`, `Tooltip`, etc.) ships with isolated `*.stories.tsx` documentation in **Storybook 10** (100% coverage):

| Component | Smartphones (`< md`) | Tablets & Desktop (`>= md`) |
| :--- | :--- | :--- |
| **`TechRadarTable`** | Stacked card list (`md:hidden`) with direct `ADR` action buttons | Full 6-column `TanStack Table` (`hidden md:block`) with sorting and filtering |
| **`D3.js` / `SVG` Graphs** | Horizontal scroll container `overflow-x-auto` with `min-w-[540px]` | Full-width interactive vector simulation |
| **`Storybook 10` (`@repo/ui`)** | Viewport presets for `360px` and `768px` contrast verification | Live toolbar switcher for `Warm Paper / Dark / Graphite / Sepia` (100% coverage) |
