## 1. Структура воркспейса `pnpm 12.21.0`, защита `allowBuilds` и `sideEffects`

Корневой `package.json` фиксирует `"packageManager": "pnpm@12.21.0"` и `"engines": { "node": ">=22.0.0" }`, а все настройки воркспейса и безопасности цепочки поставок живут **строго в `pnpm-workspace.yaml`** — никогда в устаревшей секции `"pnpm"` (вроде `onlyBuiltDependencies`) внутри `package.json`. В **pnpm 12** любые сторонние `postinstall`-скрипты заблокированы по умолчанию; компилировать нативные бинарники разрешено только пакетам из `allowBuilds`:

```yaml title="pnpm-workspace.yaml"
packages:
  - "apps/*"
  - "packages/*"

allowBuilds:
  "@biomejs/biome": true
  "@parcel/watcher": true
  "@prisma/engines": true
  "@swc/core": true
  esbuild: true
  lefthook: true
  prisma: true
  sharp: true
```

| Слой монорепозитория | Пакет | Tree-shaking (`sideEffects`) | Назначение |
| :--- | :--- | :---: | :--- |
| **Приложения (`apps/*`)** | `@repo/web`, `@repo/api`, `@repo/telemetry-ms` | — | Next.js 16 фронтенд, NestJS 12 REST API и микросервис живой SSE-телеметрии |
| **Контракты (`packages/shared-schemas`)** | `@repo/shared-schemas` | `false` | Чистые ESM Zod-схемы, DTO, константы кук/локалей и RBAC-хелперы, скомпилированные в `./dist/index.js` |
| **Дизайн-система (`packages/ui`)** | `@repo/ui` | `["*.css"]` | Матрица токенов `theme.css` / `globals.css`, Tailwind v4 `@theme inline`, примитивы `Radix UI` и `Storybook` |

> [!TIP]
> **Почему `sideEffects` различается у внутренних пакетов:** `packages/shared-schemas/package.json` указывает `"sideEffects": false`, позволяя бандлерам агрессивно вырезать неиспользуемые Zod-схемы и хелперы. `packages/ui/package.json` указывает `"sideEffects": ["*.css"]`, чтобы импорты `@repo/ui/globals.css` и `@repo/ui/theme.css` сохранялись при сборке, а неиспользуемые React-компоненты и примитивы Radix продолжали вырезаться tree-shaking'ом.

## 2. Граф задач и кэширование в `Turborepo`

Конфигурация `turbo.json` оркестрирует все 8 задач воркспейса со стриминговым выводом (`"ui": "stream"`), явной инвалидацией кэша по `globalDependencies` и `globalEnv`, топологической сборкой `"dependsOn": ["^build"]` и параллельной проверкой типов `"dependsOn": ["^typecheck"]`:

```json title="turbo.json"
{
  "$schema": "https://turbo.build/schema.json",
  "ui": "stream",
  "globalDependencies": ["tsconfig.base.json", "pnpm-workspace.yaml"],
  "globalEnv": ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"],
  "globalPassThroughEnv": ["FORCE_PNPM"],
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**", "src/generated/**", "storybook-static/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "build-storybook": {
      "dependsOn": ["^build"],
      "outputs": ["storybook-static/**"]
    },
    "typecheck": {
      "dependsOn": ["^typecheck"]
    },
    "lint": {
      "dependsOn": ["^lint"]
    },
    "test": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:coverage": {
      "dependsOn": ["^build"],
      "inputs": ["$TURBO_DEFAULT$", ".env*"],
      "outputs": ["coverage/**"],
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE"]
    },
    "test:e2e": {
      "dependsOn": ["build"],
      "cache": false,
      "passThroughEnv": ["SWC_NATIVE_BINDING_CACHE", "CI", "WORKFOLIO_DEMO_MODE"]
    },
    "dev": {
      "dependsOn": ["^build"],
      "cache": false,
      "persistent": true
    }
  }
}
```

- **`globalEnv: ["API_INTERNAL_URL", "NEXT_PUBLIC_SITE_URL"]`** гарантирует инвалидацию кэша Next.js при смене внутреннего адреса API или канонического домена (SEO canonicals, Open Graph, proxy rewrites).
- **`test` и `test:coverage`** зависят от `^build`, чтобы `@repo/shared-schemas` был собран до запуска Vitest, а **`test:e2e`** зависит от `build` текущего пакета, отключает кэширование (`cache: false`) и пробрасывает `CI` и `WORKFOLIO_DEMO_MODE`.

## 3. Каскад строгой типизации `tsconfig.base.json`

Чтобы исключить класс ошибок `Cannot read properties of undefined` в рантайме, все пакеты монорепозитория наследуют корневой профиль `tsconfig.base.json`:

```json title="tsconfig.base.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "resolveJsonModule": true,
    "allowJs": false,
    "isolatedModules": true,
    "moduleDetection": "force",
    "noEmit": true,
    "skipLibCheck": true,
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "noFallthroughCasesInSwitch": true,
    "noImplicitReturns": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  }
}
```

> [!IMPORTANT]
> Опция `noUncheckedIndexedAccess: true` автоматически добавляет `| undefined` к любому обращению по индексу массива или словаря (`items[0]`, `record[key]`), заставляя явно проверять граничные случаи на этапе компиляции.

## 4. Единый линтер, защита от циклов импортов и форматтер `Biome 2.6.4`

Вместо десятка конфликтующих плагинов `ESLint + Prettier` весь код и стили Tailwind v4 проверяются за `~100 мс` одним Rust-бинарником (`@biomejs/biome` `2.6.4`) с конфигом `biome.json`:

```json title="biome.json"
{
  "$schema": "https://biomejs.dev/schemas/2.6.4/schema.json",
  "vcs": {
    "enabled": true,
    "clientKind": "git",
    "useIgnoreFile": true
  },
  "assist": {
    "actions": {
      "source": { "organizeImports": "on" }
    }
  },
  "linter": {
    "enabled": true,
    "rules": {
      "preset": "recommended",
      "correctness": {
        "noUnusedVariables": "error",
        "noUnusedImports": "error",
        "useExhaustiveDependencies": "warn"
      },
      "suspicious": {
        "noExplicitAny": "error",
        "noImportCycles": "error",
        "noArrayIndexKey": "warn",
        "noUnknownAtRules": "off"
      },
      "style": {
        "noNonNullAssertion": "error",
        "useConst": "error",
        "useImportType": "off"
      }
    }
  },
  "javascript": {
    "parser": { "unsafeParameterDecoratorsEnabled": true }
  },
  "css": {
    "parser": { "tailwindDirectives": true }
  }
}
```

Ключевые архитектурные предохранители в `biome.json`:
- **`suspicious.noImportCycles: "error"`:** принудительно поддерживает ацикличный граф модулей на этапе линтинга как в FSD-Modular слоях фронтенда, так и в модулях NestJS — отлавливая циклические импорты до появления `undefined` DI-токенов или ошибок инициализации бандлера.
- **`javascript.parser.unsafeParameterDecoratorsEnabled: true` и `style.useImportType: "off"`:** сохраняют совместимость с декораторами параметров конструктора NestJS (`@Inject()`, `@Body()`) и рантайм-метаданными `emitDecoratorMetadata`.
- **`css.parser.tailwindDirectives: true` и `noUnknownAtRules: "off"`:** нативно разбирают директивы Tailwind v4 (`@theme inline`, `@custom-variant`) без отключения форматирования CSS.
