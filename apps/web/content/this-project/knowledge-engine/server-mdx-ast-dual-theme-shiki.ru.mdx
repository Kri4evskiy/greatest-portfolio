## 1. Архитектура маршрута `/[locale]/knowledge-base/[...slug]` и потоковый `Suspense`

Конспекты хранятся на диске по шаблону `apps/web/content/<topic>/<subtopic>/<slug>.<locale>.mdx`. Публичные URL подчиняются режиму `as-needed` в `next-intl` (английский `en` по умолчанию **без префикса**, украинский `uk` использует **`/ua`**, русский `ru` — **`/ru`**). Один catch-all маршрут `apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx` обслуживает любую глубину вложенности:

| Глубина `slug` | Пример публичного URL (RU) | Что рендерит `page.tsx` |
| :--- | :--- | :--- |
| **1 сегмент (`[topic]`)** | `/ru/knowledge-base/this-project` | **Хаб темы:** вкладки подтем (`TopicSubtopicTabs`), карточки подразделов и список всех статей раздела |
| **2 сегмента (`[topic, subtopic]`)** | `/ru/knowledge-base/this-project/knowledge-engine` | **Хаб подтемы:** активная вкладка подтемы и отфильтрованные карточки конспектов этой папки |
| **3 сегмента (`[...path, article]`)** | `/ru/knowledge-base/this-project/knowledge-engine/server-mdx-ast-dual-theme-shiki` | **Страница статьи:** `TL;DR`, `<Suspense fallback={<ArticleBodySkeleton />}>`, `MdxArticleRenderer`, правый `TOC` и `Prev / Next` |

На этапе сборки `export const dynamicParams = false` жёстко ограничивает маршрутизацию путями из `generateStaticParams()` (мгновенно отдавая `404` для неизвестных слагов), а `<MdxArticleRenderer>` обёрнут в `<Suspense fallback={<ArticleBodySkeleton />}>` (из `apps/web/src/entities/knowledge-article/ui/knowledge-skeletons.tsx`):

```tsx title="apps/web/src/app/[locale]/knowledge-base/[...slug]/page.tsx"
export const dynamicParams = false

export function generateStaticParams() {
  const slugArrays = getAllStaticKnowledgeSlugArrays()
  return SUPPORTED_LOCALES.flatMap((locale) =>
    slugArrays.map((slug) => ({
      locale,
      slug,
    })),
  )
}

// В ветке рендера статьи внутри KnowledgeCatchAllPage:
<Suspense fallback={<ArticleBodySkeleton />}>
  <MdxArticleRenderer hast={article.hast} codeBlocks={article.codeBlocks} />
</Suspense>
```

### Дедупликация через примитивно-ключованный `React.cache` (`mdx-fs-loader.ts`)
Next.js передаёт в `generateMetadata()` и `Page()` разные экземпляры массива `slug: string[]`, из-за чего прямое кэширование по массиву в `React.cache` даёт промах по ссылке. В `apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts` сегменты сначала склеиваются в примитивный строковый ключ (`segments.join('/')`), благодаря чему оба вызова разделяют один и тот же мемоизированный документ поверх межзапросного `mtimeMs`-кэша:

```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-fs-loader.ts"
const getArticleByRouteKey = cache((targetRoute: string, locale: SupportedLocale): MdxArticleDocument | null => {
  const entries = getAllCachedFrontmatterEntriesByLocale(locale)
  const matchedEntry = entries.find((e) => e.frontmatter.routePath === targetRoute)
  if (!matchedEntry) return null
  return loadCachedDocumentFromEntry(matchedEntry)
})

export function getArticleByPathSegments(segments: readonly string[], localeInput?: string): MdxArticleDocument | null {
  return getArticleByRouteKey(segments.join('/'), normalizeLocale(localeInput))
}
```

## 2. Закалённый Zero-Eval HAST-конвейер и санитайзер ссылок

Парсинг `.mdx`-файлов выполняется исключительно на сервере в `apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts`:

1. **RCE-защита `gray-matter` (`parseFrontmatterOnly`):** явно отключает legacy-движки `js` и `javascript` для исполнения кода в YAML-фронтматтере (defense-in-depth):
   ```typescript title="apps/web/src/entities/knowledge-content/lib/mdx-ast-parser.ts"
   const parsedMatter = matter(raw, {
     engines: {
       js: () => ({}),
       javascript: () => ({}),
     },
   })
   ```
2. **Zero-Eval `mdast` ➔ `HAST` (`unified`):** `remarkParse` + `remarkGfm` + `remarkDirective` размечает заголовки `h2–h4`, GitHub Alerts (`> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`), чеклисты и блоки кода, конвертирует зарегистрированные теги `<Widget />` и директивы `::sandbox` / `:::sandbox` в `div[data-mdx-widget]` и вырезает произвольный сырой HTML перед передачей в `remarkRehype` и `toJsxRuntime`.
3. **Защита от protocol-relative и `/\` обходов (`apps/web/src/entities/knowledge-content/lib/link-sanitizer.ts`):** `classifySafeMarkdownLink()` и `isSafeMarkdownImageSrc()` блокируют как `//`, так и пути с обратным слэшем `/\` (`!trimmed.startsWith('//') && !trimmed.startsWith('/\\')`), допуская только `http:`, `https:`, `mailto:` (для ссылок) и `http:`, `https:` (для изображений).

## 3. Dual-Theme `Shiki v4` с FIFO-кэшем и стилями в `theme.css` (`0 КБ` клиентского JS)

`MdxArticleRenderer` подсвечивает все `codeBlocks` параллельно через `Promise.all` и `highlightCodeServer` (`apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts`):

```typescript title="apps/web/src/entities/knowledge-content/lib/shiki-highlighter.ts"
const SHIKI_THEMES = {
  light: 'github-light-default',
  dark: 'github-dark-default',
} as const

const MAX_SHIKI_CACHE_ENTRIES = 1000

async function renderHighlightedHtml(code: string, lang: string): Promise<string> {
  try {
    return await codeToHtml(code, { lang, themes: SHIKI_THEMES, defaultColor: false })
  } catch {
    try {
      return await codeToHtml(code, { lang: 'text', themes: SHIKI_THEMES, defaultColor: false })
    } catch {
      return `<pre class="shiki"><code>${escapeHtmlFallback(code)}</code></pre>`
    }
  }
}

export function highlightCodeServer(code: string, rawLanguage: string): Promise<string> {
  const normalized = rawLanguage.trim().toLowerCase()
  const lang = LANGUAGE_ALIASES[normalized] ?? (normalized || 'typescript')
  const cacheKey = `${lang}\0${code}`

  const existing = shikiCache.get(cacheKey)
  if (existing) return existing

  const promise = renderHighlightedHtml(code, lang).catch((error: unknown) => {
    shikiCache.delete(cacheKey)
    throw error
  })

  // FIFO-вытеснение предотвращает резкую просадку (cold-start cliff) при полном сбросе кэша
  if (shikiCache.size >= MAX_SHIKI_CACHE_ENTRIES) {
    const oldestKey = shikiCache.keys().next().value
    if (oldestKey !== undefined) {
      shikiCache.delete(oldestKey)
    }
  }
  shikiCache.set(cacheKey, promise)
  return promise
}
```

- **FIFO-вытеснение (`MAX_SHIKI_CACHE_ENTRIES = 1000`):** при заполнении удаляет только самый старый ключ вместо очистки всей `Map`, исключая скачки латентности.
- **Самоочистка через `.catch()`:** мгновенно удаляет отклонённый промис из кэша, чтобы единичный сбой не отравил ключ сниппета навсегда.
- **Zero-JS CSS-каскад (`packages/ui/src/styles/theme.css`):** с `defaultColor: false` Shiki записывает переменные `--shiki-light` и `--shiki-dark`, которые переключаются чистым CSS в `@layer components`:

```css title="packages/ui/src/styles/theme.css"
@layer components {
  .shiki,
  .shiki span {
    color: var(--shiki-light);
    background-color: transparent;
    font-style: var(--shiki-light-font-style, inherit);
    font-weight: var(--shiki-light-font-weight, inherit);
  }

  .dark .shiki,
  .dark .shiki span {
    color: var(--shiki-dark);
    background-color: transparent;
    font-style: var(--shiki-dark-font-style, inherit);
    font-weight: var(--shiki-dark-font-weight, inherit);
  }
}
```

## 4. Ленивые MDX-виджеты (`next/dynamic`) и tree-shaken импорты `d3`

Все 4 интерактивных виджета в `apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx` (`ReactRenderGraphD3`, `ArchitectureFlowD3`, `NestAiMcpDiagram`, `ArticleImageGrid`) загружаются динамически с `ssr: false` и скелетонами фиксированной высоты (`min-h-[420px]` / `min-h-[320px]`), поэтому текстовые статьи без виджетов получают ровно **0 КБ** кода диаграмм и D3:

```tsx title="apps/web/src/features/kb-sandboxes/ui/mdx-client-widgets.tsx"
const ReactRenderGraphD3 = dynamic(() => import('./d3-react-render-graph').then((m) => m.ReactRenderGraphD3), {
  ssr: false,
  loading: () => <Skeleton className="my-6 min-h-[420px] w-full rounded-xl" />,
})
```

Внутри D3-песочниц (`d3-react-render-graph.tsx`, `d3-architecture-flow.tsx`) вместо полного `import * as d3` используются **именованные tree-shaken импорты** (`import { hierarchy, linkHorizontal, select, tree } from 'd3'` и `import { select } from 'd3'`), усиленные опцией `experimental.optimizePackageImports: ['lucide-react', 'd3', '@repo/ui', '@repo/shared-schemas']` в `apps/web/next.config.ts`.
