## 1. 3-уровневая таксономия под 100+ инженерных конспектов

Плоские списки перестают работать, как только база знаний вырастает за 15–20 заметок. Чтобы мгновенно находить шпаргалки в ежедневной работе и наглядно показывать системное мышление на ревью, каталог `apps/web/content/` спроектирован как рекурсивное мультислаг-дерево по маршруту `/[locale]/knowledge-base/[...slug]`:

| Уровень иерархии | Пример пути в файловой системе | Отображение в интерфейсе |
| :--- | :--- | :--- |
| **1. Тема** | `content/react/` | Свёрнутая по умолчанию ветка-аккордеон в `KnowledgeSidebar` |
| **2. Подтема** | `content/react/compiler/` | Горизонтальные вкладки подтем (`TopicSubtopicTabs`) на хаб-страницах |
| **3. Статья** | `auto-memoization-rules.ru.mdx` | Чистая страница конспекта с `TL;DR`, правым оглавлением `TOC` и `Prev / Next` |

> [!TIP]
> Клик по названию Темы или Подтемы в левом сайдбаре одновременно раскрывает ветку и открывает обзорный хаб раздела, а клик по стрелочке слева сворачивает/разворачивает папку на месте без ухода с текущей статьи.

## 2. Серверный `remark` AST, Dual-Theme `Shiki` (0 КБ JS) и статический роут `Cmd+K`

Вместо отправки парсеров и библиотек подсветки в браузер `mdx-content.ts` разбирает фронтматтер через `gray-matter` и строит рекурсивное `mdast`-дерево через `unified` + `remark-parse` + `remark-gfm` строго на сервере, а `MdxArticleRenderer` вызывает `Shiki v4` с парными CSS-переменными (`github-light-default` / `github-dark-default`, `defaultColor: false`).

Аналогично, чтобы глобальная палитра `Cmd+K` масштабировалась за 100+ конспектов с `0 КБ` в начальном HTML страниц, статический SSG-роут `app/search-index/[locale]/route.ts` собирает индекс на этапе билда, а `CommandPaletteModal` подгружает и кэширует его по требованию:

```typescript title="apps/web/src/lib/mdx-content.ts"
export function getKnowledgeSearchIndex(locale: SupportedLocale): KnowledgeSearchItem[] {
  return getAllArticlesForLocale(locale).map((article) => ({
    routePath: article.routePath,
    title: article.title,
    sidebarLabel: article.sidebarLabel,
    topicLabel: formatKnowledgeSegmentLabel(article.category, locale),
    subtopicLabel: article.slugSegments[0]
      ? formatKnowledgeSegmentLabel(article.slugSegments[0], locale)
      : '',
    format: article.format,
    tags: article.tags,
    headings: article.toc
      .filter((h) => h.level === 2 || h.level === 3)
      .map(({ id, text }) => ({ id, text })),
  }))
}
```

## 3. Подход Architecture-First и открытая доска компромиссов

Вместо смешивания визуальных экспериментов с базовой архитектурой мы последовательно закрыли Этапы 1–5 и вывели интерактивный реестр **Инженерный бэклог, Tech Debt и компромиссы** (`/#roadmap`) прямо на главную страницу:

- **Следующий шаг (`P1`):** Визуальный редизайн в тёплой эстетике оригинального **Notion Workfolio (UI v2)** поверх уже готового и строго типизированного ядра.
- **Прозрачный Tech Debt:** строгие заголовки `CSP / HSTS`, `@nestjs/throttler` и ротация `Access + Refresh` JWT перед публичным облачным деплоем.
- **Осознанные компромиссы (`Deferred`):** аргументированный отказ от БД-админки (Headless CMS) и платного векторного LLM RAG-чата в пользу мгновенного бесплатного поиска `Cmd+K` по версионируемым в Git файлам `.mdx`.
