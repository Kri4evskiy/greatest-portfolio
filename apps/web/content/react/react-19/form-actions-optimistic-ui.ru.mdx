## 1. Мгновенный отклик интерфейса через `useOptimistic`

```tsx title="Оптимистичное обновление счётчика без задержки"
'use client'
import { useOptimistic } from 'react'

export function HelpfulButton({ count, onVote }: { count: number; onVote: () => Promise<void> }) {
  const [optimisticCount, addOptimistic] = useOptimistic(count, (curr, delta: number) => curr + delta)

  return (
    <form
      action={async () => {
        addOptimistic(1)
        await onVote()
      }}
    >
      <button type="submit">Полезно ({optimisticCount})</button>
    </form>
  )
}
```

## 2. Выбор между нативными Form Actions и `React Hook Form`

| Сценарий | Нативный React 19 `<form action>` | `React Hook Form` + `Zod` + `TanStack Query` |
| :--- | :--- | :--- |
| Быстрая мутация из 1–2 кнопок/полей | **Идеально** (`0 KB` стороннего кода) | Избыточно |
| Живая клиентская валидация по `Zod` | Ручной маппинг ошибок по полям | **Идеально** (`zodResolver` + изоляция подписок) |
| Offline-First синхронизация с `IndexedDB` | Нет встроенного кэш-слоя | **Идеально** (единый стор `TanStack Query`) |
